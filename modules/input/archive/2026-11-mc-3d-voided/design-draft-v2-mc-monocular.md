# 输入模块设计草案 v2：MC 单路画面到整帧射线

【用户已确认】MC 首版采用单路 2D 视角＋可锁定相机参数 K；先稀疏，再赋方向射线。相机没有测深，`ray.depth` 保持未测，推算／预测深度禁止写回观测。

【开放/未决】`mechanismValidated: false`。本稿是输入侧候选设计，具体字段见 [接口契约](interface-contract.md)；不声称真实 MC 采集、正式 ingest 或机制已验证。

## 一、当前流程

【候选方案】按状态侧 [06c](../state-network/S-SPACE-06c-image-to-pattern.md) 的整帧流程及 [07](../state-network/S-SPACE-07-relative-layout.md) 的相对位置口径对齐：

```text
一张完整画面＋本帧来源与时间＋匹配的锁定 K／拓扑
  → 检查采集配置、尺寸、像素约定与帧绑定
  → 保留原位置的稀疏测量
  → 为每个保留点赋 origin／direction／coordinate_frame
  → 所有 ray.depth 均为 {"status":"unknown"}
  → 全帧检查通过后，一次交出全部亮点集合
  → 状态侧 A 按固定规则在固定 RF 上沉积自然场

A 的只读活动／原观测引用＋K＋适用的范围或几何依据
  → 状态侧 A 外按条件计算左右、近远、条件坐标
  → 缺依据就不产出对应项；有真错配就硬失败
  → 不回写原观测，不改 ray，不重新沉积 A

成熟模块 → 仅接在 A 外作解释／先验
```

【候选方案】A 固定，变化的是本帧画面与 S-SPACE 活动；输入不决定 RF 核宽、沉积预算、计算域或网络动力学，不以解释是否成功决定合法画面能否自然成像。整帧交付也不要求新建对象、占据或历史账本。

### 1. 锁定采集与画面几何

【候选方案】取得实际 MC 采集配置，记录版本、视角模式、画面尺寸、投影／K、FOV 的轴向与含义、像素中心和图像变换。经过独立投影核对后固定这些参数；每帧的 `geometry_ref` 引用相符版本，不能逐帧调 K 迎合画面。

【候选方案】首个几何候选限定为无畸变针孔、原画面不裁剪不缩放，像素 u 向右、v 向下；相机局部 x 向右、y 向下、z 向前。像素中心约定由描述显式声明，不从分辨率猜主点。需要裁剪／缩放等另一种处理时另列完整几何版本，在双方支持前报不支持。

【用户已确认】几何／K 真错配硬失败。【候选方案】尺寸、投影、原像素与 ray、锁定配置或本帧绑定出现矛盾就停止整帧交付；不能自动修射线、换 K、补像素或返回已算好的半帧。

【开放/未决】真实 MC 的版本、FOV／投影导出、采集认证、HUD／准星／手持物等覆盖的处理方式尚未确定。摘要可核对绑定，不能单独证明真实相机正确；仅有彼此自洽的 metadata 不足以排除整体错误。状态实验中的合成 K 不作真实 MC 默认值。

### 2. 在原位置做稀疏测量

【候选方案】采用分块局部对比 topK 作为评审起点，每块最多保留 k 个非零对比位置，不够就少留。K 专指相机内参，k 表示保留数。传输时列 `position_index` 与 `intensity`，拓扑仍描述原画面的高、宽、行列与邻接；不把索引改成强度排名。

【开放/未决】块大小、是否重叠、邻域和边界、正对比／绝对对比、噪声门槛、并列次序、幅度归一以及到 A 的强度映射均待拍板。旧稿的 topK 方向与展示参数不扩大本轮六项确认；06c 的 8×8、每块两点等只属于其合成配置。

【候选方案】未列位置不提供测量，不表示自由空间；稀疏选择也不签发对象、几何边或方块数量。合法完整画面可得到空集合；缺图、局部缺测或坏图不能转成空集合。不为达到预算填零或补点，未声明误差不当作零误差。

### 3. 赋方向射线，距离保持未测

【候选方案】在上述针孔与本帧相机局部参照下，用锁定 K 将保留像素 p=(u,v,1) 变成方向：

```text
q = K⁻¹ p
direction = q / ||q||
origin = [0,0,0]                 # 本帧相机光心，坐标定义
ray(λ) = origin + λ·direction    # λ>0，距离没有测量
depth = {"status":"unknown"}
```

【候选方案】这里的归一化是适配器按成像关系生成单位方向；接收端若收到不合法方向则报错，不静默归一化修补。相机局部原点的零是坐标定义，不是未知世界位置填零；没有合法外参就不声明世界坐标。

【用户已确认】`ray.depth` 保持未测，禁止把条件计量、成熟模型预测或其他推算深度写回观测或 `ray.depth`。【候选方案】本轮不提供距离、终点、深度区间或深度假设，也不另设 `depth_evidence` 暗渡这些数值。前向深度 Z 与沿单位 ray 的距离 λ 在 A 外解释时也须区分。

【开放/未决】参照命名、长度单位、单位转换与像素／角度误差的表达需联合签认。方块单位和模型米的关系必须显式，不能因旧字段曾写米就默认一块等于一米。

### 4. 整帧一次交给状态

【候选方案】一帧构成一个 `VisionSparseEvent`，携带全部 `samples`、来源、采样时间及拓扑／几何引用。收发双方按整帧检查：任何必需字段或样本错误都使本帧失败。内部可以遍历 ray，对外不逐 ray 渐进发布，不扫角或沿深度逐次试探一个答案。

【候选方案】视觉评审起点是 `update_mode=snapshot`、`frame_complete=true`；本帧接纳后一次替换该单路外部输入驱动。完整空帧只有“本帧没有选中亮点”的含义；缺测不伪造空帧、不延长旧采样时间，输入也不据此清除 S-SPACE 内部持续活动。

【开放/未决】完整快照的字段表示、序号与重复身份、迟到拒收、驱动截止时间和容量上限仍须联合拍板。本稿不新增逐帧台账；状态侧 06 已指出旧接口的重复幂等与后续冲突硬失败口径有差异，不能写成兼容已经完成。

## 二、A 外相对位置与成熟模块

【候选方案】依 [07](../state-network/S-SPACE-07-relative-layout.md)，K 解释像素对应的射线方向；要从方向进一步得到三维左右、近远或条件坐标，必须有适用的完整范围、尺度或等范围依据。端点是否完整、方向是否满足计量模型、范围属于几块或哪些范围确实相等，均不能从亮点或“MC 由方块组成”直接补出。

【候选方案】已知各自完整范围时可分别产生条件坐标；只知共同范围 S 时，可产生以 S 为单位的条件坐标与前向近远关系；缺少相应依据就不产生该项数值。画面 u 的左右与三维 X 次序分开，前向 Z 与沿射线 λ 分开；不把画面中更大的范围无条件判成更近。

【候选方案】不对结果设置 resolved／inconsistent／partial 分类，不用 unknown 结果桶代替缺失计算，也不补 0、N=1、默认距离或历史答案。`ray.depth.status=unknown` 只表达相机未测深。若提交的依据真实错配，该请求硬失败，不能捕获错误后改成只返回 A 的成功请求。

【候选方案】条件计量与成熟辅助均在 A 外，保留所用观测引用、依据与来源；不能替代 S-SPACE 底座，不能改写原 ray、输入强度、采样时间或 A 的沉积。辅助若需要原始稠密图，其读取范围须另议；当前视觉事件不因此自动扩展。

【用户已确认】输入不交对象 ID、地图或配方；自然成像不贴真假标签。【候选方案】几何描述和来源标识也不能夹带隐藏位置、深度缓冲或答案表，成熟模块的预测不能经输入口冒充观测。

| 拍板点 | 具体问题与边界 |

| P4 单路整帧与时序 | 【开放/未决】`session_id/source_id/frame_id/event_id/sequence`、时钟、完整快照字段、缺测通知、截止时间、重复／迟到处理及容量。 |

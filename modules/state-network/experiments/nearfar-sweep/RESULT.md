# 【候选】固定三维感受野的 Minecraft 尺度 near/far 扫描

【候选结论】首轮可用的**承载计算域**候选为：相机组局部坐标 **z ∈ [0.25, 16] 米**。在本夹具声明的 **1 方块边长＝1 米**下，即前向 **0.25–16 方块**。主要依据是 **0.5 米基线、0.5–12 米真值深度**的测试工作负载；范围相当于 **0.5B–32B**。固定感受野中心间距与高斯 σ 均为 **0.125 米**，位置不学习。

【候选结论】更紧的 **z ∈ [0.25, 12.5] 米**也覆盖这批测试支持域，可作为计算预算较紧时的对照。16 米是粗扫描网格中的选择，给 12 米测试点留下 4 米前向余量，**不是实验发现的唯一最优边界，更不是已验证的定位距离**。没有真实输入深度分布，不能把这两个数字提升为 Minecraft 部署默认值。

【未验证】`mechanismValidated: false`。本实验实际执行了固定感受野的前馈数值沉积、逐路叠加和一种候选共支持增强，没有执行递归网络、学习、实例识别或真实 Minecraft 端到端实验。覆盖成功不证明深度消歧成功；共支持增强存在明确假交汇失败。

## 2. near/far 到底相对什么

【候选定义】局部原点取两光心的中点，x 向右、y 向上、z 向前。near/far 是两个**前向深度平面**，不是球面半径，也不是相机渲染裁剪参数，更不是从像素测得的物体边界。

对于光心 z＝0、单位方向 d 且 d_z＞0 的射线，计算段为：

```text
λ_near = near / d_z
λ_far  = far  / d_z
x(λ)   = origin + λ·direction
```

【候选定义】因此斜射线的 λ 通常大于同位置的 z。报告范围写 z 米；沿 ray 活动宽度写 λ 米，二者没有混用。横向不另裁一个狭小箱子，而对输入射线沿途的固定空间节点求值；完整视锥的容量未做基准测试。

【边界】**域外＝未承载，不是测得空区。**读出域外返回 NaN。评分覆盖率把域外计为漏覆盖，但不把它变成空世界证据。即使输入射线对应的真实点在 far 外，该射线仍可能在域内驱动一条支持带；网络不知道那个真实深度，不能用评分真值提前删掉它。

## 3. 实际实现的【候选乙】基线

【用户已确认范围】固定、重叠的三维感受野，位置不学。本实验没有改动概念网络，也没有学习任何状态侧权重。

【候选数值实现】`field.py` 的单元中心位于固定三维空间格点 `c = h × (i,j,k)`，每个单元具有重叠的各向同性高斯感受野，σ＝0.125 米。h 扫描 0.125/0.25 米。格点只是固定感受野中心的数值排布，**不是逐射线的硬深度箱列**；不同射线共享这些单元。连续读出使用三线性插值，越过格点边界时活动连续。

每条 ray 对单元 c 的驱动是有限射线段的高斯积分：

```text
a_r(c) = intensity / (σ√(2π))
         × ∫[λ_near, λ_far] exp(−||c − origin − λ·direction||²/(2σ²)) dλ
D_view(c) = max over this view's rays a_r(c)
single(c)   = D_left(c)
sum(c)      = D_left(c) + D_right(c)
enhanced(c) = D_left(c) + D_right(c) + 4 D_left(c)D_right(c)
```

【候选实现说明】

- 积分用 erf 的解析式求值；横向超出 4σ 的高斯尾数值置零。σ 是本次表示尺度，未冒充传感器角误差。没有因远处变宽而移动或学习感受野。
- 本次采用**每单位射线长度固定注入**，不是每 ray 固定总预算，也不是深度概率。延长域会增加全场活动总量，但同一内部位置不会仅因域长度改变而按 `1/(far−near)` 被稀释。指标比较使用局部活动与同一真值支持域，未用全域总亮度声称证据变强。
- 同路取 max 作为本次有界合并候选，避免同路点数直接冒充独立支持；这会丢弃同路累计信息，是未获批准的实验简化。
- 左右分别 ingest，记录来源、独立帧号和像素位置；同源别名先合并。共支持项逐空间单元计算，没有跨路 ray 配对表，没有三角化求点。
- `field.py` 不读取真值文件。评分读出按需求值固定格点，中心位置始终由 h 与全局坐标确定；真值只决定评估在哪里读数，不能移动单元或改变驱动。这是惰性求值的前馈基线，不是已经实例化并演化的全视锥神经网络。
- 共支持增强只是一个保留单路底量的代数对照，没有递归竞争、抑制、沿线再分配或吸引子动力学。不能把上述公式写成已批准机制。

## 4. 扫描、指标和选择规则

【实验配置】粗扫描 near＝0.125/0.25/0.5/1/2 米；far＝4/8/12/16/32/64 米；B＝0.06/0.5/1 米；h＝0.125/0.25 米。核心组共有 180 个参数组合，每个比较三种活动读出。加上边界细扫、扩展深度、双解、无共同点、孤立点和像素扰动对照，共 **306 个组合、918 行模式结果**。

【实验指标】

1. **真支持域覆盖**：对每个真值点周围半径 0.25 米的固定球形评估域取 257 个样本。几何覆盖＝位于 near/far 内的比例；活动覆盖＝域内且读出≥0.05 的比例。分母始终包括整个球，不因裁域而缩小。报告均值和最差单点。该阈值是本次实验假设；沿线泛亮也能得到高覆盖，不能据此证明定位。
2. **沿 ray 的 W80**：以 z 步长 0.125 米沿每条输入 ray 取样，按活动值由高到低选择承载至少 80% 活动质量的样本，保留阈值处全部并列项。返回区间并集及总 λ 长度，不能用质心隐藏多峰。无活动返回空值；单路模式只评左路射线。另记录是否触碰域边界。
3. **假交汇相对强度**：在独立评分文件指定的假支持球内取最大活动，除以真实支持球峰值的中位数。只统计预先知道的反例区域，**不是全场假峰发现率**。普通场景没有穷举假交汇，相关列留空而不是填零。
4. **截断影响**：用相同夹具、相同 RF、相同评分域，在 z＝0.125–96 米参考域计算活动质量；报告扫描域保留的比例，并另报几何漏覆盖。参考域自身也有限。参考活动为零时比例留空。

【候选选择规则】在核心 B＝0.5 米、h＝0.125 米、普通叠加组，要求每个真支持球几何覆盖≥99%、活动覆盖≥95%，在粗扫描网格中选最大的 near、再选最小的 far。规则和阈值已写入 `run.py`/`results/config.json`；这是针对声明工作负载的覆盖选择，**不含“已消歧”要求**，不能冒充经过外部验收的标准。

## 5. 实测结果

【候选实验结果】核心 B＝0.5 米、h＝0.125 米，普通叠加：

| near–far（z 米） | 真支持域平均活动覆盖 | 最差单点覆盖 | 相对参考域平均活动保留 | 沿 ray W80 中位数（λ 米） |
| --- | ---: | ---: | ---: | ---: |
| 0.125–16 | 100% | 100% | 100.00% | 11.98 |
| 0.25–8 | 76.59% | 0% | 72.93% | 5.89 |
| 0.25–12 | 93.26% | 59.53% | 89.59% | 8.90 |
| **0.25–16** | **100%** | **100%** | **99.34%** | **11.85** |
| 0.25–32 | 100% | 100% | 99.34% | 24.46 |
| 0.25–64 | 100% | 100% | 99.34% | 49.80 |
| 0.5–16 | 93.26% | 59.53% | 91.21% | 11.66 |
| 1–16 | 76.59% | 0% | 73.68% | 11.41 |
| 2–16 | 59.92% | 0% | 56.91% | 10.78 |

【解释】near＝0.5 切过最近 z＝0.5 点的支持球，far＝12 切过最远 z＝12 点的支持球。边界平面上的样本计为域内，因此离散球的截半比例为 59.53%，不是连续球理论上的恰好 50%。较短域下 W80 更小主要是删掉了可承载范围，不能叫更准。0.25–16 对最近点仍只保留参考活动的 **96.04%**，平均数 99.34% 不能掩盖这一端点效应。

【候选实验结果】随后对边界细扫，明确检查 16 是否只是粗网格造成的：

| near–far（z 米） | 最差单点几何／活动覆盖 | 平均参考活动保留 | 解释 |
| --- | ---: | ---: | --- |
| 0.25–12.125 | 91.44% / 91.44% | 94.70% | 仍切掉最远支持球。 |
| 0.25–12.25 | 100% / 100% | 98.01% | 刚好包住评分球，但端点沉积仍衰减。 |
| **0.25–12.5** | **100% / 100%** | **99.31%** | 更紧的承载对照，W80＝9.28 米。 |
| 0.25–13 | 100% / 100% | 99.34% | 在本数据上与 16 的真支持保留几乎相同。 |
| 0.3125–12.25 | 99.61% / 99.61% | 96.89% | 也满足所设门槛，说明门槛和网格会改变选择；并非完整覆盖。 |

【候选解释】因此保留 **0.25–16 米**作为较宽的首轮计算窗口，**0.25–12.5 米**作为紧窗口对照，而不声称 16 是唯一最优。前者相对最远测试深度是 1.33 倍，后者为 1.04 倍；0.25 米 near 比最近点前方多留 0.25 米，即本次 2σ 的表示余量。该余量不能自动外推到另一 RF 宽度或另一场景。

【候选实验结果】在 0.25–16 米、h＝0.125 米域内，核心六点的沿 ray W80 中位数：

| 基线 B（米） | 单路（λ 米） | 普通叠加（λ 米） | 共支持增强（λ 米） |
| --- | ---: | ---: | ---: |
| 0.06 | 12.48 | 12.07 | 11.33 |
| 0.5 | 12.61 | 11.85 | 10.68 |
| 1.0 | 12.56 | 12.08 | 10.52 |

【限制】W80 仍然很宽，不能宣布已取得逐方块深度分辨率。尤其 B＝0.06 米小于本次 RF σ＝0.125 米；即使承载范围取 16 米（约 267B），也不意味着能在 16 米处可靠定深。增强保留了单路沿线底量，域越长，底量所占质量越大；这会使 W80 随域扩大，不能拿本指标宣称基线越大必然全局更优。

【密度与扰动对照】B＝0.5、0.25–16 米时，h 从 0.125 变为 0.25 米，真支持覆盖仍为 100%，但普通叠加 W80 从 11.85 变为 11.39 米，增强从 10.68 变为 10.29 米。这个变化属于表示／读出敏感性，不能把粗采样较小的数值认作更准。0.5 像素扰动三个种子中，核心覆盖均为 100%，普通叠加 W80 为 11.85–11.91 米；样本少、RF 较宽，不能据此宣称噪声鲁棒性已验证。

## 6. 明确失败样例

【候选实验结果：同等支持的假交汇】复现可行性稿 §2.4：真实点为局部 (−0.5,0,5)、(0,0,5) 米；替代交汇为 (−0.5,0,10)、(−1/6,0,10/3) 米。两路只交未配对像素射线。在 0.25–16 米、B＝1 米、h＝0.125 米下：

| 模式 | 假／真支持球峰值比 |
| --- | ---: |
| 单路 | 1.000 |
| 普通叠加 | 1.000 |
| 共支持增强 | 1.000 |

【解释】共支持增强没有压掉等证据假交汇。把 far 改成 8 米时该比值看似降为 0.898／0.844（叠加／增强），但 z＝10 的合法替代支持被截到域外；这不能作为成功消歧证据。单路的比值也不是“交汇检测结果”，只是单条支持带对评分位置的活动。

【候选实验结果：两路没有共同真值点】左路只保留第一个真值点，右路只保留第二个，两条未配对射线在 z＝10 米产生错误共支持：普通叠加假／真峰值比 **1.999**，共支持增强升至 **5.188**。因此本增强项可能**放大错误交汇**，没有资格据此签发对象或精确深度。

【候选实验结果：扩展深度截断】加入 0.125–72 米的 13 个真值点后，0.25–16 米平均覆盖只有 **57.08%**；扩到 32/64 米升为 **72.46%/83.27%**，仍漏掉极近、域外远点及部分边界支持。这说明首轮候选依赖明确的任务深度范围，不适用于全部可见世界。

【候选实验结果：视野与串扰】B＝1 米时，z＝0.5 米的近点不在任一相机视野内。孤立点测试活动覆盖为 **0%**，但多点核心场景的同一真支持球仍被其他射线覆盖了 **99.61%**。这直接说明“真支持覆盖高”也可能包含无关射线串扰，必须结合来源、共同可见性与假交汇指标读结果。

【候选实验结果：远点仍然很宽】z＝48 米单点、0.25–64 米域、0.5 像素扰动下，增强 W80 为：B＝0.06 米 **49.25–49.69 米**，B＝0.5 米 **36.81–37.75 米**，B＝1 米 **38.38–40.44 米**。这些是所选保底增强读出的宽度，不是三角化误差，也不能据此给出精确远点位置。扩大 far 只提供承载空间。

## 7. 开放假设与下一批拍板点

【开放】本轮证据不足以确定真实 Minecraft 的最终 near/far：还没有真实相机基线／投影／时间误差、真实稀疏样本分布、任务距离需求和共同点保留率。固定 RF 位置已确认，但 σ、中心密度、最大合并、单位长度注入、增强系数 4、评分球半径与阈值均只是本次实验候选。没有检验移动、历史持续、遮挡、自由空间推断或概念反馈。

【待拍板】

1. 首轮是否以 **0.25–16 米承载窗口**与 **0.25–12.5 米紧窗口**继续对照，而不把它们写入正式接口默认值？

# 【候选】【完整设计方案】S-SPACE-06c：输入图像到空间图案

【候选】本方案完成用户收窄后的目标：**把一张图像转换为 S-SPACE 中可复算、可读取的空间活动图案。**实现已落在 [mc-image-to-pattern](experiments/mc-image-to-pattern/RESULT.md)，包含实际 PGM 入口、稀疏观测摘录、固定承载、图案读出与独立的 B 条件计量。以下默认均已写入候选代码；`mechanismValidated: false`。

## 1. 【候选】目标、范围与假设

【候选】入口保留单路二维画面 → 稀疏亮点＋ray；深度入口为 `unknown`。本轮的成功口径是：合法图像及相机参数经过完整处理后，得到有坐标、尺度、来源与数值定义的活动读出。没有左右图、双目配对、对象 ID、地图或隐藏命中答案；不把活动图案称为完整稠密 3D 重建。

【用户已确认】沿用 [06b](S-SPACE-06b-block-scale-prior.md)：路径 B 采用单位方块边长 `b=1 个方块单位` 作为显式几何先验。

【用户已确认】沿用 06b：MC 相机参数固定且可确定；从真实 MC 锁定版本、FOV 与投影后，把 K 视为已知内参，不逐帧猜测。

【候选】A 采用固定成像／承载规则：固定 RF、近远域、每 ray 总预算均摊、整帧沉积、普通叠加；帧与活动随输入变化。自然成像不贴真假标签，不按图案形态筛掉输入。B 和成熟辅助在 A 外解释，不改写相机观测。

【候选】当前可执行入口是 ASCII P2 灰度图及显式元数据；合成夹具生成这样的图后，也经过同一读取入口。其他图像编码须明确转换为与 K 一致的 P2，本程序不猜解码、不自动裁剪或缩放。当前按一帧的采样时刻离线求值，不新增历史追踪、动作闭环或实例账本。

## 2. 【候选】端到端数据流

【候选】完整流向如下；b 通过单位约定参与几何尺度解释，不能用来替未知 ray 选终点。

```text
P2 图像 + 本帧 capture + 锁定的 K + 显式配置
  → 检查像素、投影、版本、图像／相机绑定
  → 分块局部对比 topK，保留二维位置与强度
  → K 生成每点单位 ray；depth.status 始终 unknown
  → 块单位与模型米的显式映射，确定固定 RF／计算域
  → 全部保留亮点整帧交给 A：沿线均摊、普通叠加
  → 按需求值：225 个空间探针 + 25 个剖面点
  → pattern.json / probes.csv / profile.csv / 单色探针示意 SVG

同一稀疏观测 + K + b + 可选适用条件
  → A 外的 B：可见分界计数 → 条件深度，或 unknown
  → B.json；不回写 ray.depth，不改 A 的值

成熟深度辅助 → 明确未连接的 stub；无预测值
```

【候选】`pipeline()` 在完整验证之后构造当前帧的承载对象，完成全部请求的探针／剖面计算，再形成结果。内部遍历 ray 和数值积分只用于完成整帧计算，不逐 ray 发布，不扫角、不沿深度试探选择答案。每次调用只计算本帧，没有把上次活动累加到新帧的路径。

## 4. 【候选】真实 MC 的 K 如何锁定

【候选】真实接入采用一次锁定、逐帧绑定的方式：固定 MC 版本与采集配置，取得实际投影及画面尺寸，明确像素中心／坐标变换，得到 K；通过已知投影检查后保存锁定记录。所有会改变投影或像素映射的设置必须在该记录的适用范围内；不能固定或不能表示的成像方式，当前 profile 报不支持，不每帧拟合补救。

【候选】优先从实际投影确定 K。若使用 FOV 公式，必须先明确真实 FOV 的轴向、投影定义和像素约定；不能把未经核对的菜单数字直接当垂直 FOV。当前 FOV 公式只核对本实现声明的对称针孔模型；其他主点、畸变、裁剪或缩放不在这个版本中静默兼容。

【候选】锁定记录保存来源、渲染版本、K、FOV、尺寸与变换约定；capture 保存本帧图像摘要、锁定记录摘要、同一渲染版本和采样身份。程序核对三者后才生成 ray，内部一致性使用数值容差，不把容差当测量误差上界。实际配置不符、绑定不符或已发现真实几何不符均硬失败。

【开放】真实 MC 投影导出与采集工具尚未接入；本轮运行证据使用明示合成 K。`mc-locked-export` 是离线记录可使用的来源种类，不代表已有 MC 连接。摘要只能验证文件绑定与内部一致性，不能认证记录本身符合真实相机；真实性仍须实际采集／投影核对，不能靠改摘要掩盖错配。

## 5. 【候选】A：固定自然成像载体与空间图案口径

【候选】对当前帧全部保留 ray，令 `r(λ)=o+λd`，`Λ={λ>0 | r(λ)∈Ω}`，长度为 L；固定单元中心 cᵢ 与帐篷基 `φᵢ(x)=∏轴 max(0,1−|x轴−cᵢ,轴|/h)`。本方案承载计算为：

```text
a_i,r = (Q_r/L_r) ∫[Λ_r] φ_i(o_r+λd_r) dλ
A_i = Σ[本帧全部保留 ray] a_i,r
Σ_i φ_i(x)=1，因此 Σ_i a_i,r=Q_r
```

【候选】所有合格 ray 按同一规则自然沉积；场与亮度没有真假分类。实现只保有当前输入及参数，局部积分按需计算；没有按三维网格维护占据账本、对象表或历史活动表。全域单元枚举只在预算检查时求和，不是运行时必须密铺存储的前提。

【候选】“空间图案”指这个有空间参照的 RF 活动及其有限读出。`pattern.json` 保存实际求得的探针／剖面；CSV 保留坐标和值，SVG 仅把同一批探针的活动映射为圆面积，统一半径 5 对应活动 0.1，不逐图归一化或挑峰。图中未采样位置没有被算作零，SVG 不是稠密表面、占据图或深度图。

【候选】计算域只限制承载范围，不是物体深度先验；缩短域不能证明定位变准。未知误差不补零、不自动加宽 RF。合法完整平坦图可能产生零个亮点，此时零活动是已完成的空和；缺图、坏图与未求值不能按这个空和处理。

【候选】单位转换显式使用 `x_m=s·x_block、h_m=s·h_block`，域边界同步乘 s；K 与单位方向不变。当前 s=1 是模型约定。将 s 改为 2 后，同一块坐标探针的单元活动应不变，B 的块单位深度不变、模型米数值加倍；此检查已通过，不据此声称现实尺度已测量。

## 6. 【候选】B：最小可核验的可见边→N→条件深度

【候选】B 只读已保留的二维位置、K、b 和独立适用条件，不读取世界点、N 答案或深度真值。本轮没有通用 MC 方块语义识别器；先实现可核验的“正对相机、连续单位块缝”类别。适用条件必须绑定当前图像，且不得携带 N、距离或对象 ID。

【候选】最小识别策略：按像素行聚合保留位置，取至少含三条分界的行；要求至少两行相隔 4 px，所有这些行的分界列位置一致，连续列间距相等。得到分界列数 k 后，**实际计数 `N=k−1`**，以首末分界之间的投影宽度 p 计算 `Z_blocks=fx·N·b/p`。Z 是相机前向深度，不自动等于沿单位 ray 的 λ。

【候选】当前条件文件的来源严格限于合成目标类别声明：它声明单位缝语义及平行视面条件，不包含这张图的 N 或深度。分界计数和图像一致性由程序核验；“条纹确实是块缝”不由等间距外观自动证明。实际 MC 未取得这类适用依据时，默认返回 unknown，不借相似纹理冒充已经识别。

【候选】两条线不足以通过当前规则，不直接当一块；缺缝、不同图像行列位置不一致、非等间距或没有适用依据，也返回带原因的 unknown，省略 N 与深度数值。它们仍对应 A 中原有的射线支持；没有“算不出就用 N=1”的路径，也不以有限候选列表冒充穷尽所有深度解释。

【候选】条件满足时，`B.json` 单独给出计数 N、像素依据、条件来源及条件 Z。它不写回 `samples[].ray.depth`，不把预测／条件计量改称相机测深，不重新沉积、不修改 A 的预算或场值。对图案的几何解释与自然图案本身保持区别。

【开放】重复纹理、遮挡后漏掉每隔一条缝、未保留端点等仍可能有相同的稀疏外观；条件声明不提供通用语义认证。N 的一般识别与实际 MC 条件验证仍未实现，当前仅验证受限类别的识别过程与“认不出就保留未知”的行为。这不阻塞本轮图像→A 图案目标。

## 8. 【候选】错误与硬失败

| 标记 | 条件 | 当前行为 |
| --- | --- | --- |
| 【候选】 | 图像缺失、格式不支持、量程／像素数非法 | 报错、CLI 非零退出，不填像素、不替换图像。 |
| 【候选】 | K 缺失／非法，FOV、尺寸、变换或帧绑定错配 | 硬失败，不猜 K、不裁图、不修 ray、不沿用替代配置。 |
| 【候选】 | 单位比例或预算依据缺失／非法 | 硬失败，不补 1 或 0。 |
| 【候选】 | 域外、非 RF 中心、请求超过读出上限 | 硬失败，不返回部分查询或伪零。 |
| 【候选】 | B 缺适用依据、保留特征不足或识别不能确定 | 正常返回 unknown，A 的合法自然活动仍可读；没有条件深度数值。 |
| 【候选】 | B 所给依据与当前图像错配，或明确声明真实几何不符合所请求模型 | 该请求硬失败，不改条件／换模型继续报成功。 |
| 【候选】 | 成熟辅助未接入 | 默认 stub 明示未连接；请求其他未实现模式则报错。 |

【候选】B 不是 A 自然沉积的资格门。包含 B 的请求若发生硬错误，CLI 报错且不发布该请求产物；它不会捕获错误后偷偷返回只有 A 的“成功”。调用者可以显式独立运行不带 B 条件的 A 读出。未知深度与已发现的几何错配有不同语义，不能混为同一种错误或同一种兜底。

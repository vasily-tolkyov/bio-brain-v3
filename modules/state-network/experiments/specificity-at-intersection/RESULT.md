# S-SPACE 交汇处特异性：位置与光强结构的合成验证

【候选结论】**有条件能响应，不等于普遍可分。**共同观测、正确对应、有效几何与时序、足够分离及已知强度标定和保留集合由场景保证时，本次所测位置／光强变化可以进入场；变化还必须没有被量化或稀疏化抹掉。这里“正确对应”是对照场景和评分已知的关系，没有作为新字段交给承载，也没有被场自行确认。未配对稀疏输入可被多套世界共享，因而整个确定性场相同；仅靠固定 RF 沉积和普通叠加不能保证唯一的「3D 像」。**这不等于每一个未配对输入都必然多解，也不等于每一种位置变化都必然改变场。**

【关键证据】理想点移动 `(0.1, 0.05, 0.5) m`，真值邻域内的活动极值跟随，位移误差 **3.494 mm**；然而，两组空间点集相差约 **5 m** 的不同场景能产生**完全相同的保留输入、逐路活动与合计场**。这直接否定普遍唯一的空间解释。该结论依据场景不可区分性，不以“更亮＝成功”或旧实验的“假／真峰值比”定义成功。

【05B 范围】在原 28 个场景上增补到 **93 个场景**，覆盖密集／多点结构、同深度不同基线、未声明的轻微扰动、部分共同可见、24 世界同输入和亚像素位移。原 56 个输入／真值文件保持逐字节一致，载体公式未改。仍为 **`mechanismValidated: false`**；全部材料是合成证据，没有接入 Minecraft、真实相机、输入 topK 或神经动力学。

## 1. 承载边界与实现

【用户已确认】输入→承载按自然成像处理；不筛、不标交汇／假交汇／真假对错，不按亮度签发成功。所有已保留亮点整帧加载，各路新帧即时整路替换。一路、两路和更多路都使用同一沉积与相加规则；合法射线未交于一点不报错。

【实验配置】两种前向 **z** 窗口分别为 **0.25–16 m**、**0.25–12.5 m**；固定 **σ＝0.015625 m、h＝0.0078125 m**。这些是条件性实验起点，不是接口默认。RF 不移动、不学习、不随未知误差加宽。

【模型】[carrier.py](carrier.py) 只读导入 [support-width-sweep/field.py](../support-width-sweep/field.py)。复用固定帐篷基＋截断归一高斯的预算分配和三线性密度读出，不修改旧文件。每条 ray 的总预算显式取 `Q=intensity`，在域内沿 λ 均摊：

```text
a_i,r ≈ (Q_r / N_r) Σ_k φ_i(o_r + λ_k d_r)
Σ_i φ_i(x) = 1；Σ_i a_i,r = Q_r
D_v,i = Σ_r∈本路完整帧 a_i,r
A_i = Σ_v D_v,i
```

【边界】内部逐 ray 求积只是整帧计算，不逐 ray 发布；新帧完成后替换该路旧驱动。没有来源乘积、配对、三角化、竞争、抑制、选峰沉积或历史累积。实验按需计算固定单元，临时数值缓存只服务当前输入，不新增固定账本。这里不是完整输入契约 API 或并发运行时验证。

【未知与零】除 `A-zero-declared` 显式声明零测量误差外，输入误差均未声明，保持 `unknown`；模拟器的精确投影、量化或指定扰动另存在真值文件。域外和非有限读出直接报错。不适用指标使用 JSON `null`／CSV 空列并写原因；不把未知误差或未求值填零。有限核确实无贡献、完全相同数组作差得到的数值零，是计算结果，不是补缺值。

## 3. 「特异性」怎样测量

【候选定义】把“位置响应”“光强结构响应”“与其它合法场景可区分”分别测量，不合成一个亮度通过分数。前两项出现理想响应，仍不能替代第三项。设场景为 S，保留输入为 E(S)，确定性承载为 F(E)：

```text
如果目标位置或光强结构不同，而 E(S₁)=E(S₂)，
则 F(E(S₁))=F(E(S₂))。
相同的整个场不能唯一指定两种不同现实中的某一种。
```

【必要条件，不是完整充分性证明】在被讨论的场景范围内，不同目标属性不能总映为同一证据／同一场。完全相同的反例可以否定普遍特异性；不同场之间测得非零距离，仅证明本次无噪声对照有差异，不能自动证明可靠可读出。

| 指标 | 明确定义与实现 | 解释限制 |
| --- | --- | --- |
| 真值邻域极值位置 | 在每点周围半宽 `(0.04,0.04,0.5) m` 的盒内读固定全局 h 格点；报告最大值节点到真值的距离 | **评分预知位置**，不是从全场自动定位。并列极值不平均成一个点，位置／误差列留空，另报集合的最近／最远距离和是否触边。 |
| 位移跟随 | A 两个静态快照的唯一邻域极值位移，减去真位移，取欧氏范数 | 不是跨帧身份跟踪，也不证明对其它场景唯一。 |
| 深度近峰范围 | 在真值 x/y 的 z 轴剖面上，以 h 采样，保留达到该剖面峰值 95% 的样本；报区间、外包跨度和样本长度 | 95% 是剖面宽度量，不是真假、置信或成功阈值；多个区间不能当作连续实物。 |
| 支持域内外对比 M | 真值半径 2 cm 球的并集内／外，分别取声明探针上的最大值 I、O；`M=(I−O)/(I+O)` | 探针包含局部盒、每条输入 ray 的全窗口剖面、真值轴及 B/C 预设干扰位置盒；**非全体积**，也不保证每个暗点都保留。M 正值不是特异性证明。 |
| 场景可区分性 δ | 相同探针 Q 上，`max(abs(F₁−F₂))/max(abs(F₁))`；另核对逐路分量与完整物理输入 | B/C/E 的输入完全相同给出全场等式；数值核对不是靠有限网格“发现所有场都相同”。位置差用点集 Hausdorff 距离，位置不同不强行对应强度。 |
| 邻物影响 | 保持第一点不变，增加第二点；计算第一点处增加活动／原活动；另比较等预算归一剖面的相对 L2 距离 | 同时报告中点／端点活动与局部极值数，均只是固定剖面统计，不从峰数推对象数。 |
| 强度缩放与结构 | 固定位置和保留集，以 `α=(F₀·F)/(F₀·F₀)` 测全局缩放，报残差 `‖F−αF₀‖₂/‖F‖₂`；归一后另比结构差 | α 的逆映射只在同几何、同集合、正标量变化条件下成立。 |
| 已知几何强度对照 | 用每个已知位置的独立单位亮度夹具获得增益 g，再测 `F(X)/g` | 是评分端的条件性标定，不是从未知场景恢复物体的算法；保留集合改变时不报告原强度逆解误差。 |
| 不读真值的场差（05B） | [input_only.py](input_only.py) 只读事件；固定 rig 网格与两输入全部 ray 的全窗口采样并集上，报告相对 L∞、归一形状 L2、缩放残差和逐路差 | 探针不依赖真值邻域，也不选峰。对照场景对仍是预先给定的，不是让算法识别未知现实。非零差证明该对照有变化，不能推出唯一世界；不同输入的有限探针零差也不能推出全场相同。 |
| 已知几何串扰（05B） | 离线以正确对应构造每点双路单位强度输入，得 `Gᵢⱼ=Fⱼ(Xᵢ)`；核对 `F(X)=G·I`，报 `(F(Xᵢ)−GᵢᵢIᵢ)/(GᵢᵢIᵢ)` | 此项刻意预知位置／对应，是评分端分解。它检验单点增益是否被邻物贡献污染，不是未知几何逆解或筛选模块。 |

【指标参数】2 cm、95%、局部盒大小及数值并列容差均是本次候选诊断约定，不升为机制验收标准。没有复用“假／真峰值比”作为最终成功定义。

## 5. 不可区分的现实场景：决定性的反例

【B：无共同保留点】`B-common` 的唯一点为 `(-0.5,0,10)`。`B-no-common` 有 `(-0.5,0,5)`、`(0,0,5)` 两点，左路只保留前者，右路只保留后者；这与旧 `no-common-point` 的保留样本逐项相同。两场景都交付左像素 `(640,360)`、右像素 `(560,360)`，强度均 0.8。两条 ray 在 `(-0.5,0,10)` 数学相交。无共同点指无共同**保留观测点**，不是没有数学交点，也不要求上游两相机没有共同可见点。

【C：重复样本】两种现实点集分别是：

```text
C-flat:              {(-0.5,0,5), (0,0,5)}
C-depth-alternative: {(-0.5,0,10), (-1/6,0,10/3)}
```

【C 输入】各点均共同可见、全部保留、强度 0.8。两种场景均投影到左图 `u={640,720}`、右图 `u={480,560}`，均在 `v=360`。不提供对应的输入完全相同。本例将[理论边界第 2.4 节](../../../input/feasibility-minecraft-dual-ray-3d.md#24-两路像素不等于已知对应点)的坐标原点平移到相机组中点，并落实为相同 RF 的数值场。

| 不同现实场景对 | 真值差异 | 保留物理输入 | 合计场 δ | 逐路最大 δ |
| --- | --- | --- | ---: | ---: |
| B-common / B-no-common | 点集 Hausdorff **5.024938 m** | 完全相同 | **0** | **0** |
| C-flat / C-depth-alternative | 点集 Hausdorff **5.000000 m** | 完全相同 | **0** | **0** |
| E-drop-both / different-world | 同位置被删点强度 **0.5 → 0.9** | 完全相同 | **0** | **0** |

【证据范围】上述等式在两种窗口都成立，见 [aliases.csv](results/aliases.csv)。每对核对 10,836–14,929 个查询点；全场相同的依据是同一确定性承载获得相同物理输入，**不是有限探针穷举了所有空间**。独立实验的 session/event 编号不用于制造物理差异。

【为什么不以局部峰为结论】C-flat 两个真值邻域的极值误差都为 0，但同一个场也对应另一套点集。在 `x=−0.5,y=0` 剖面上，95% 近峰区间为 **[4.968750,5.031250]** 与 **[9.929688,10.070313] m**，外包跨度 **5.101563 m**。评分真值换成 C 的另一种场景后，M 从负变正，场本身没有变化。因此评分端知道的真值不能当成场已经具有的区分能力。

【候选结论】这些相同活动既不能确定“这个交汇对应哪个现实位置”，也不能确定是哪一个物体的光强结构。即使读取逐路分量，B/C/E 反例仍相同；保留来源不自动补出丢失的对应或强度信息。这里没有讨论或实现筛选算法。

## 6. 邻近第二物体：局部活动会混合

【结果】同一 z＝2 m 平面，两点分别位于 `x=±d/2`，每点强度 0.4；增加第二点前，第一点及其输入不变。另以中心强度 0.8 单点比较相同总预算。以下为主窗口，见 [neighbors.csv](results/neighbors.csv)。

| 间隔 | 第二点在第一点处增加的相对活动 | 中点／较小端点活动 | 固定剖面局部极值数 | 等预算归一形状相对 L2 差 |
| --- | ---: | ---: | ---: | ---: |
| 2 cm | **48.089%** | **1.142096** | 1 | **0.152094** |
| 4 cm | 5.4874% | 0.905005 | 2 | 0.487546 |
| 8 cm | 约 5.03×10⁻¹⁰（比例） | 0.089522 | 2 | 1.027553 |
| 16 cm | 0（有限核计算结果） | 约 2.70×10⁻⁹ | 2 | 1.221846 |

【解释】2 cm 时，一个位置的活动不能直接归因于该处物体自身强度，邻物贡献显著；该剖面只有一峰。**但等预算形状差仍为 15.21%，所以合峰不等于两场完全不可区分，也没有证明数学分辨极限就是 2 cm。**8 cm 的所测端点干扰很小，只支持该几何、该位置的有限结论；未证明全场没有其它叠合，更未证明对象身份。

## 7. 光强结构：可保留变化，不能补回未观测部分

【统一缩放】几何和保留集合不变时，三点 `[0.25,0.5,0.8]` 统一乘 0.5 或 1.25，测得 α 分别为 **0.5**、**1.2500000000000002**；主窗口拟合相对残差分别为 **0**、**2.7745×10⁻¹⁶**。两种窗口最大残差均低于 **3×10⁻¹⁶**。这是线性算式在浮点计算中的核对，不是现实光度精度达到这个量级。

【非统一变化】将强度换成 `[0.8,0.5,0.25]`，总 ray 预算仍为 **3.1**，主窗口归一场结构相对 L2 差为 **0.779129**。因此所测光强结构变化有可观测差别，不能把这一结果仅概括成“整体更亮”。见 [scaling.csv](results/scaling.csv)。

【条件性逆映射】已知三个位置且完整保留时，逐点独立单位亮度增益下 `F(X)/g` 恢复原强度；所测最大相对数值误差为 **1.78×10⁻¹⁶**。这里的 g 来自额外的已知几何标定实验；不表示承载已自行获得物体位置、对应或真实光度标定。RF 格点相位与方向造成不同增益，不能把原始密度当真实光强直接照抄。

【保留集合变化】只删右路中间点时，该处实际真值亮度仍为 **0.5**，但沿用完整双路 g 得到的响应为 **0.248784**。这不是物体变暗的证据。两路都删去它时，在本有限核与点间隔下该处活动为计算上的 0；评分**不把它逆解为现实强度 0**。把该被删点真实强度改到 0.9 后，所有活动仍完全相同。见 [photometry.csv](results/photometry.csv) 与 E 的成对反例。

【窗口对照】A 原点从主窗口改为紧窗口，局部峰密度由 **64.660812** 变为 **83.125098**，约 **1.28556 倍**；真值和输入强度没变。均摊长度理论因子为 `15.75/12.25=1.285714`，小差异来自求积。窗口改动也会改活动增益，不能以更亮解释为恢复得更好。

## 8. 05B：响应、评分预知与未知世界可分性的边界

【三个层次】真值邻域极值、真值轴剖面和单位增益均预知位置／对应；只能回答“这些已知位置附近有什么响应”。`input_only.csv` 的 36 对、两种窗口共 72 次对照不用真值选探针，回答“给定两份事件产生的活动是否有差异”。二者都没有实现从未知输入恢复现实场景。全场不可区分的严格证据来自**相同输入**，不是从有限探针零差推断。

【固定探针规则】不读真值的读出采用 rig 坐标网格：x＝−0.75…0.75 m、y＝−0.25…0.25 m、z＝0.25…当前 far，步长均 0.125 m；再并入两份输入所有 ray 上以 4h 采样的点。没有围绕真值挑查询点，也没有按场峰或亮度挑候选。每对记录查询点数和 SHA-256，本次范围为 7,112–58,735 个点；这不是整个视锥的连续穷举。详见 [input_only.csv](results/input_only.csv)。

【密集与更多点】F/G 的四组位置分别整体移动 `(0.035,0.025,0.2) m`，或逆序交换强度、或强度减半。换位前后总 ray 预算相同，减半是线性控制。位置诊断仍使用原来的全局 h 格点和同尺寸真值盒；盒可能覆盖邻点，不能将每个盒的极值自动视为该点自身。已知几何分解另见 [mixing.csv](results/mixing.csv) 与 [known_geometry_response.json](results/known_geometry_response.json)。

【J 数值】276 对点集 Hausdorff 距离范围为 **0.05–1.388889 m**，不是同一套点的重新编号。23 对×2 窗口的合计与逐路场差均为 **0**。连同 B/C/E/H/K，全部 **28 对×2 窗口＝56** 个同输入对照均如此；相同物理输入加确定性承载才是全场等式的依据。

【量化边界】K 将 A 的同一共同点横移 0.5 mm，理想像素均平移 0.2 px；量化后的像素、强度、ray 与整个输入不变，逐路及合计场也相同。即使共同观测成立，小于本次采样可区分范围的位置变化也可能根本没有进入输入。不能把“所测变化能响应”改写成“任何位置变化都能响应”。

## 10. 失败、限制与开放问题

【失败与限制】

1. B/C/H/J 是不同现实位置映为相同输入与全场的严格反例；E 是被稀疏化删除的真实光强变化完全不可见的反例；K 是量化抹掉共同点位移的反例。它们不是承载报错，也不把场划成真假区域。
2. A 的局部极值跟随、E 的条件性强度逆映射支持有限正面结论；共同点、同步、标定、保留集合与真值邻域均由合成夹具保证，尚无场内自证。没有以这些有利条件宣称普遍「3D 像」。
3. 局部评分利用真值；05B 只读事件的探针增加了不预知邻域的场差核对，但没有全视锥极值普查、真实场景识别率或未知世界恢复。多个真值盒甚至可指向同一个唯一最大节点；近峰跨度、M 和剖面峰数也都不是最终成功定义。
4. 未知误差保留未知；1／8 px 控制及确定性标定偏差不建立误差分布或可靠包络。没有自动加宽 RF，没有从误差未声明推定实际误差为零；真实场景没变时，扰动本身也能改变场。
5. 点状光强、固定视角、单位增益对照及给定稀疏集合，不能代表连续表面、遮挡、反射、曝光变化、传感器噪声、动态场景或完整现实光强分布。所测变化的非零场差不等于噪声下可稳健区分。
6. 未验证全视锥容量、实时性、物体边界与实例身份；没有设计筛选模块。原场始终按自然成像规则保留。

【开放】哪些实际保留集合能提供足够的共同观测；什么任务位置容差与光强结构误差才算可用；真实测量误差、曝光和幅度怎样标定；在这些条件下，哪些不同场景仍给出不可区分证据。以上需要新的证据，不能由本次局部极值或零数值残差代答。

【修改边界】05B 只修改本实验内的夹具生成、离线评分／核验脚本、fixtures、results 和本文，以及 [S-SPACE-05 讨论备忘](../../S-SPACE-05-specificity-at-intersection.md)。`carrier.py`、只读导入的旧 field、`architecture.json`、输入契约、S-SPACE-03/04、理论边界和其它实验均未修改。没有机制状态升级、兜底、账本、未知填零或筛选模块。

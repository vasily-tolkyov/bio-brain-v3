## 【用户已确认】
- 稀疏路径：保留位置的稀疏输入 → S-SPACE 分布式活动峰 → 相互作用形成整体
- Q1-A：分块局部对比 topK（展示实现≠机制验证；K 等参数仍开放）
- 适配器先稀疏测量，再赋视线/射线；输入侧不钉死世界三维点
- 单视角：方向射线，深度可未知
- 多视角：各路独立稀疏矩阵 + 独立射线；交汇成 3D 由状态侧活动叠出，输入侧不先配对
- 交给状态网络：随时间演化的两路（或多路）稀疏输入矩阵，分别注入
- 无 Minecraft 对象 ID/地图/隐藏属性/配方；要有原生基本三维能力（深度不确定表达仍开放）

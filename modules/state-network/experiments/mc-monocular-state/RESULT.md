# 【候选】MC 单目状态：最小合成核验结果

【用户已确认】MC 首版是一张二维画面＋相机参数，默认传入稀疏 2D 亮点＋单路 ray；没有左右图、没有配对。场不贴真假标签，几何真错配硬失败；无兜底、无固定账本、无填零、不加颜色。`mechanismValidated: false`。

【候选】本次 **32 项合成断言通过**。两个不同深度的世界产生完全相同的单幅画面、稀疏输入和承载活动；因此这些输入不能区分实际是哪套世界。这个结果支持[研究稿](../../S-SPACE-06-mc-monocular-state.md)中保留未知深度的必要性，**没有完成 MC 接入或稠密 3D 重建**。

## 2. 【候选】成像、稀疏化与承载条件

| 标记 | 项目 | 显式实验设置 |
| --- | --- | --- |
| 【候选】 | 图像 | 高 48、宽 64，共 3,072 像素；像素中心取整数坐标，行优先索引。 |
| 【候选】 | 相机 | `fx=fy=48 px`，`cx=32 px`，`cy=24 px`；无畸变针孔投影，无裁剪缩放。 |
| 【候选】 | 参照 | 采样时刻的相机局部参照，x 向右、y 向下、z 向前；光心按定义为 `(0,0,0)`。 |
| 【候选】 | 场景 | 三个不透明、正对相机、恒定辐亮度的矩形表面；最近正深度交点可见，背景辐亮度为 0.125。 |
| 【候选】 | 两套世界 | near 的全部表面在 z=4；far 将 x/y/z 一起乘 2，表面在 z=8，保持辐亮度。没有将远世界塞进另一路。 |
| 【候选】 | 稀疏化 | 8×8 块、像素与块内均值的绝对差、每块最多两个非零样本、并列按原索引；本次保留 20 点。 |
| 【候选】 | 强度编码 | 明示除数 1.0，`Q=1.0×intensity`；不把该比例补给缺失标校准的真实输入。 |
| 【候选】 | ray | 根据 K 和像素生成单位方向；全部共用同一光心，`depth.status=unknown`，没有方向／深度答案表。 |
| 【候选】 | 测量误差 | 未向承载声明误差；不补为 0、不自动改宽。渲染器理想无噪声不等于实际相机精度已知。 |
| 【候选】 | 计算域 | `[-7,7]×[-5,5]×[0.5,12.5]`，长度在夹具中显式记作 m；不是实测 MC 单位标定。 |
| 【候选】 | RF | h=0.5 的固定格点和三维帐篷基 `φ_i(x)=∏_axis max(0,1−abs(x_axis−c_i,axis)/h)`；域内基函数和为 1。 |
| 【候选】 | 求值 | 沿 ray 固定预算均摊；局部 RF 积分按基函数折点分段，每段二点 Gauss 积分，不储存全场或固定账本。 |

【候选】该 RF 是便于复核的独立数值候选，不复用或修改旧实验的高斯组合核与 σ。按需计算只支持本实验固定 RF 中心的查询；非格点读出报错，没有偷偷插值或补零。全中心枚举仅用于预算核验，不是要求运行时密铺存储。

【候选】缩放不改变投影，因为 `(sX)/(sZ)=X/Z`、`(sY)/(sZ)=Y/Z`。矩形覆盖条件与最近可见次序也保持，恒定辐亮度使整张标量图相同。PGM 是便于查看的 8 位量化文件；相等性在量化前的浮点渲染图上也已检查，不是量化凑出的相等。

【开放】真实 MC 的方块纹理、光照、雾、阴影和后处理可能改变画面，实际稀疏化也可能留下或删除不同线索。这里没有验证某个实际 MC 世界对必然同图，也没有假定“单位方块”已提供了可识别的已知长度。实验只证明在明确成像模型下存在单帧多解。

## 3. 【候选】结果与含义

| 标记 | 检查 | 结果 | 可据此判断的范围 |
| --- | --- | --- | --- |
| 【候选】 | 不同世界的画面 | z=4／8；最大亮度差 0 | 同一相机下，三维表面位置和尺寸不同仍可同图。 |
| 【候选】 | 保留输入 | 两份 20 点稀疏输入连同 ray 完全相同 | 承载没有收到能区分这两套世界的信息。 |
| 【候选】 | 固定空间探针 | 207 个；最大活动差 0 | 数值控制一致；全场相同另由相同输入及确定性算子推出。 |
| 【候选】 | 整帧预算 | 15,225 个 RF 中心；ΣQ=ΣA=5.9375，绝对差 0 | 当前合成域和 RF 的预算守恒，非真实测量零误差。 |
| 【候选】 | 单 ray 剖面 | Q=0.4，z=1…12 的内部中心活动约 0.0166666667 | 无唯一深度；near/far 附近的端部变化来自计算域。 |
| 【候选】 | 域长控制 | z 窗口从 `[0.5,12.5]` 改为 `[0.5,6.5]`；内部活动比 2，总量仍 0.4 | 域裁短提高活动密度，不提供新深度证据。 |
| 【候选】 | 强度控制 | Q 从 0.4 到 0.8；活动比 2 | 只验证线性预算响应，不把亮度解释成距离。 |
| 【候选】 | 保留角度变化 | 亮点横移 1 px，最大探针活动差 0.0083333333 | 该输入变化进入三维活动，不说明沿 ray 深度可分。 |
| 【候选】 | 查询顺序／重读 | 顺序逆转及再次读出数值一致 | 没有每次查询再沉积一份预算；未测试并发／网络重放。 |

【候选】固定探针来自相机局部坐标 `x∈{−2,0,2}`、`y∈{−1,0,1}`、`z=1,1.5,…,12`，不围绕真值挑峰。独立积分核对的另 12 个探针仅从输入 ray 在固定 z 平面的格点邻近位置取得，不使用场景文件。

【候选】两份观测沿用相同的流／帧标识，是因为它们表示“同一采集条件下的两个替代世界”；分别构造两个纯计算对象，从未作为同一运行流中的两次观测累加。这不授权真实入口接受重复身份。

【开放】相机真实标定来源、相机参数与采集帧的实际绑定、内部一致但整体错误的几何、身份真实性、流式替换／到期、并发、资源耗尽等尚未验证。脚本不借这些未验证项设置兜底，也不把自洽检查当作实际标定认证。

# S-SPACE-08 · 2D toy · 图像平面活动图最小设计稿

【用户已确认】当前主线是全新 2D 架构：第一版状态网络只承载 S-SPACE 活动图。本稿依据 2026-11-04 本轮用户任务简报，不重写旧 01～07 或旧实验。

【开放/未决】`mechanismValidated: false`。本文是最小设计稿；字段与跨模块接线尚待联合签认，没有运行实现或机制验收结论。动画成功 ≠ 逻辑验证。

## 1. 范围与非目标

【用户已确认】本版只做三件事：接收保留原位置的真实稀疏点，将强度直接写到同尺寸密网格，交出本帧活动图。每格仅有强度，每帧整图覆盖。

【用户已确认】本版无峰、无归组、无局部极大提取，无相机→世界映射；不保留 S-INSTANCE／S-SOURCE／S-HAVE／S-WANT 四个职责盒，不用别名或附表恢复这些职责。不叠上一帧、不做衰减叠帧、不自留历史。

【用户已确认】观测口只收适配器真实稀疏测量；补全／回映／推算不得写入观测活动格。禁止预装 MC 对象 ID／地图／隐藏属性／配方。无兜底、无账本，不填未知为零，不加工程 status taxonomy。

【开放/未决】输入侧稀疏算子细节、概念学习公式、动作动力学不在本稿定案范围；跨模块接口变更需「原型设计」群对齐。本轮不改 `data/architecture.json`、ports／edges 或其他模块正文。

【历史参考】旧 CONTEXT、[01](S-SPACE-01-sparse-feature-to-spatial-peak.md) 的“稀疏→峰”以及旧五职责叙事不作本版默认；[阶段纪要](../../sources/pm-status-2026-11-04-2d-reset.md)中仍待设计五盒的说法，由本轮“只留 S-SPACE”活动图定稿取代。旧稿原样保留，阅读入口见 [README](README.md)。

## 2. 已确认前提

1. 【用户已确认】**入口**：2D 画面经分块局部对比 topK 稀疏后进 S-SPACE；保留点含原位置＋强度；可带颜色且颜色可参与 topK 加权，但颜色进状态格是后选项。输入不预装对象 ID／地图。块大小／k／权重等参数等状态设计后再调（本稿不定死参数）。
2. 【用户已确认】**点亮方式**：输入 topK 稀疏化后的点**直接点亮对应格**（图像平面活动图），**不做**相机→世界映射。
3. 【用户已确认】**峰**：第一版状态网络**只承载活动格**；「峰」等概念网络学习／补全读出后再传回状态网络才出现，**不在状态侧先做峰／归组／局部极大**。
4. 【用户已确认】**跨帧**：每帧整图覆盖，不叠上一帧、不衰减叠帧；连续感在世界本身，不在状态网自留历史。
5. 【用户已确认】**职责盒**：删掉 S-INSTANCE／S-SOURCE／S-HAVE／S-WANT；第一版**只留 S-SPACE 活动图**，后面有必要再加。
6. 【用户已确认】**存储**：整幅密网格，没点到的格为 0。
7. 【用户已确认】**格载荷**：第一版每格只要**强度**；颜色可选后加。
8. 【用户已确认】**分辨率**：跟输入画面同尺寸，一点一格。

## 3. 2D 世界与一帧契约

【用户已确认】S-SPACE 的坐标就是输入画面的图像平面坐标，大小为 H×W；H、W 随交接画面，不另设状态网格分辨率。画面中的移动只体现为下一帧点亮位置改变，不由状态网推算轨迹或建立地图。

【候选方案】为使交接可核对，本稿用左上角为原点、x 向右、y 向下的整数像素坐标；数组写作 `A[y][x]`。借用旧契约的 `position_index`，约定行优先：`position_index = y × W + x`，反解为 `x = position_index % W`、`y = floor(position_index / W)`。这只是地址展开，不是几何投影；坐标约定与字段名需群对齐。

### 3.1 输入：一帧稀疏集合

【候选方案】下表是一帧完整稀疏集合的最小交接形状，不是已实现 API。字段名尽量借用[旧输入契约](../input/interface-contract.md)，含义以[输入 v3](../input/design-draft-v3-2d-toy.md)和本轮八条定稿为准。

| 字段 | 类型与含义 | 范围 |
| --- | --- | --- |
| `frame_id` | 本次画面标识；具体类型待签认 | 【候选方案】仅关联当前帧，不是对象 ID。 |
| `shape` | `[H, W]`，两个正整数 | 【候选方案】直接携带输入高宽；与旧 `TopologyDescriptor.shape` 同义，放在帧内还是引用描述待对齐。 |
| `source_id` | 画面采集来源标识 | 【候选方案】帧级元数据，不建立 S-SOURCE、来源账本或逐格来源表。 |
| `sampled_at`、`clock_id` | 采样时间与对应时钟标识 | 【候选方案】只标明这帧何时采集，单位待签认；不引入历史缓存或衰减。 |
| `samples` | 稀疏点列表，可为 `[]` | 【候选方案】一次交出完整集合；空列表仅表示本帧没有保留点。 |
| `samples[].position_index` | `0 ≤ index < H×W` 的整数，同帧唯一 | 【候选方案】保留原画面位置，不能用强度排名代替。 |
| `samples[].intensity` | 有限正数，原值交接 | 【候选方案】具体尺度待签认，不预定 `(0,1]`、阈值或归一方法。 |
| `samples[].color` | 可选；字段名及编码待签认 | 【开放/未决】输入可以带颜色；本版不写入状态格。是否随帧交付及不消费它的约定需群对齐。 |

【开放/未决】若分块重叠导致同坐标重复，需输入与状态共同确定交接集合如何满足唯一位置假设；本稿不替输入指定去重算子，状态侧也不擅自取最大、求和或平均。缺必需字段、越界或强度不符合约定时，不补默认值、不做静默修复；具体交接处置另行对齐，不增设状态分类。

### 3.2 输出：一帧密活动图

| 字段 | 类型与含义 | 范围 |
| --- | --- | --- |
| `frame_id`、`shape` | 与输入本帧一致 | 【候选方案】保持一帧对应关系，不生成对象或实例标识。 |
| `source_id`、`sampled_at`、`clock_id` | 本帧元数据原样随读出交接 | 【候选方案】不进入格载荷，不积累历次记录。 |
| `intensity` | H 行、每行 W 个数的密数组，即 `A[y][x]` | 【候选方案】字段名待签认；密网格、每格仅强度的内容已确认。 |
| `color` | 后加字段占位，本版不分配 | 【开放/未决】是否增加颜色通道、编码及未点亮位置的表示以后再定；不先填零、空值或默认颜色。 |

【用户已确认】未点亮格的 0 只表示“本帧无活动”，不表示测得黑色、世界为空、没有物体或未知值为零。被 topK 留下的点之外，状态网没有补出新测量。

## 4. 注入规则

【用户已确认】每帧以整幅无活动网格开始；每个保留点仅将自身强度写入对应 `(x,y)` 格，其余格为 0。新帧替换整幅旧图，不把旧活动、推算或补全加进来。

【候选方案】按第 3 节字段表示，规则可写成以下说明性伪代码；不是可执行实现或额外机制：

```text
A_t = H×W 的全 0 活动网格
对本帧 samples 中每个点：
    x = position_index % W
    y = floor(position_index / W)
    A_t[y][x] = intensity
本帧读出 = 本帧元数据 + A_t
```

【用户已确认】写入不扩散、不插值、不先找峰或分组；点强度不在状态侧重新参与 topK。`A_t` 的计算不读取 `A_(t-1)`，没有累加项或衰减项。

【候选方案】消费者一次读取完成的一帧，避免把写入中的局部格当整帧；具体交接时序待签认，不据此增加队列、历史副本或运行状态表。

【开放/未决】完整空帧的 `samples=[]` 必须得到全 0 活动图；没有收到完整帧则没有本帧 `A_t`，不能伪造空帧，也不能用上一帧冒充本帧观测。断流、迟到和尺寸切换的交接细节需群对齐；本稿不设超时清零、续帧或寿命默认值。

## 5. 读出与峰的后置

【用户已确认】第一版读出活动图本身。单个亮格、相邻亮格或视觉上的亮斑都只称活动格；状态侧不生成峰列表、局部极大、连通组、对象或实例。

【候选方案】向概念侧交本帧密强度图及对应的图像位置、帧元数据；不要求状态先压成峰或归组，也不把像素地址当概念神经元编号。概念侧怎样读取与编码，由概念模块共同确认。

【开放/未决】峰读出须等概念网络学习／补全读出并回传后再定。仅含观测活动图的 S-SPACE 如何承接这些峰、保持位置对应，又不覆盖观测格，尚无落点方案。本版不实现回传峰写入，也不先加第二张图、实例表或来源账本作为默认答案。

【用户已确认】补全／回映／推算不能改写 `intensity` 观测网格，不能伪装成下一帧 `samples` 再进观测口。后续峰如何表达是开放项，这条隔离边界不是开放项。

## 7. 与概念／动作的最小接线假设

【候选方案】最小逻辑交接为“输入真实稀疏帧 → S-SPACE 活动图 → 概念侧读取”。这不是新 ports／edges 的定稿；是否沿用现有端口名、如何接 C0，需群对齐。本版不承诺概念学习、动作闭环或回传峰已经接通。

【用户已确认】沿用[最新用户定义](../../sources/latest-user-decisions.md)中仍有效的非几何边界：状态三因子只校 C0 吸引子内部连接，高层由下一层非三因子校准；返回仅是信号通路，没有返回强度。真实输入触发的直接与补全活动可学习，内部预演不学习，遮挡／缺测照常小幅削弱。本稿不新增公式或改变概念学习边界；格内观测强度不等于返回强度。

【候选方案】动作／目标若需当前视觉，只能把活动图作为当前观测依据；动作命令、回执和预测不得直接点亮格，外部结果必须经下一帧真实输入进入。身体、目标、经历的承接位置不在本版 S-SPACE 内代建。

## 8. 升 3D 钩子

## 9. 最小可核验项

【候选方案】以下仅核验稀疏点到活动格的契约。统一使用合成 H=3、W=4 和任意示例强度；这些数值不是分辨率、强度尺度或 topK 参数默认。以逐格数组比较为依据，不依赖动画，也不声称验证了输入稀疏算子或概念能力。

| 合成场景 | 输入要点 | 可核对的预期 |
| --- | --- | --- |
| 单点点亮 | `samples=[{position_index:6, intensity:0.7}]` | 仅 `A[1][2]=0.7`，其余 11 格为 0；尺寸仍为 3×4。 |
| 双点分离 | 同帧索引 5 为 0.4、索引 6 为 0.9 | `A[1][1]=0.4`、`A[1][2]=0.9`，其余为 0；相邻弱点也保留，不合并、不用局部极大删点。 |
| 空帧全 0 | 一帧完整输入，`samples=[]` | 全部 12 格为 0；可接在非空帧后检验清除。结论仅为本帧无活动，不是世界为空。 |
| 次帧覆盖 | 前帧索引 5 为 0.4、6 为 0.9；次帧仅索引 6 为 0.2、10 为 0.7 | 次帧 `A[1][1]=0`、`A[1][2]=0.2`、`A[2][2]=0.7`，其余为 0；旧点不残留，同址不累加也不衰减相加。 |

【候选方案】每项同时核对输出尺寸、帧标识和强度原值；输入到读出之间不插入峰提取、归组或几何变换。合成样本只用于核验，不登记为真实采集；另需在交接审查中确认补全／推算没有写入观测格的路径。

【开放/未决】本轮只列核验项，尚未实现或执行上述合成检查。即使以后四项全过，也只支持本节的承载与覆盖规则，`mechanismValidated: false` 仍保持。场景大纲见 [2d-toy-model/README](experiments/2d-toy-model/README.md)。

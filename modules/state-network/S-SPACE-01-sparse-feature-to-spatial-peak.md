## 三、候选机制：两个对照方案，均未选定

### 候选甲：位置保持的局部投影

【候选方案】在一个观测窗口内，将每个稀疏样本的位置映射到活动载体的局部支持域，按样本强度分配活动贡献；相邻输入位置对应相邻或重叠的支持域。对贡献的合并采用待定的有界方式，形成可测量的局部活动隆起。

【候选方案】将「位置映射 → 局部贡献 → 合并活动」作为最小成峰对照；窗口内不引入递归邻接传播。窗口结束如何清除活动须与输入快照 / 增量语义共同确定，不默认具有跨时记忆。

【开放/未决】投影是固定几何映射还是可调整映射、支持域宽度、合并上界、边界处理均未决定；这里的局部投影并非批准某种输入稀疏算法。

【候选方案】该方案用于检查保位与多点分布是否足以产生可读峰形；预计风险是把输入噪点直接变成峰、把近邻证据混成一个峰。若峰形只是投影核的复制，不能据此证明整体形成或实例识别。

### 候选乙：局部投影后有限邻接交换

【候选方案】复用候选甲的同一份注入证据，再在待定空间邻接上进行有限轮活动交换，以比较局部证据聚合前后的峰形。可试验质量守恒的邻接扩散并配合非负、有界约束；轮数与尺度均是待比较参数。

【候选方案】记录每轮活动质量、峰宽及峰位变化；如果邻接交换扩大无证据区域的活动或吞并可区分的峰，则将该参数配置记录为失败，而不以视觉平滑为成功。

【开放/未决】候选乙尚无获批的邻接图、交换规则或持续活动机制；「局部驱动+邻近支持抑制」未获批准，不作为候选乙的既定实现，也不在此预置抑制环路。

【候选方案】该方案可用来检验邻接交换是否降低孤立噪声相对局部一致证据的显著程度；其风险是扩散展宽、峰位漂移与近邻峰合并，是否有收益须由数值对照回答。

| 对照维度 | 候选甲 | 候选乙 |
| --- | --- | --- |
| 【候选方案】共同条件 | 同一输入、位置映射、初始活动、强度尺度与读出规则 | 复用左列共同条件 |
| 【候选方案】变化因素 | 仅注入与合并 | 注入后增加有限邻接交换 |
| 【候选方案】重点观测 | 保位误差、支持域宽度、噪声峰 | 相对甲的峰宽变化、漂移、误合并与噪声显著度 |
| 【开放/未决】能力边界 | 不完成整体形成或跨时续接 | 邻接交换本身也不证明整体形成或跨时续接 |

【历史参考·非本模块确认】[newnet/spec.md](/workspace/newnet/spec.md) 中「点亮平面附近一群神经元」仅作局部映射的历史参照；同文包含撤回重设说明。其二维撒点、STDP、光谱传播与参数不直接继承到以上候选。

### 从输入证据到活动峰

1. 【候选方案】先校验位置、坐标描述、强度编码及窗口完整性；无法解释的载荷不进入活动更新，保留失败原因供接口核对。
2. 【候选方案】用显式映射把输入位置对应到活动载体的局部位置；记录映射版本，并测量局部邻接是否保留，不用类别或对象 ID 选择目的区域。
3. 【候选方案】按强度编码转换为待定的活动贡献尺度，再按候选甲或乙更新活动；算子输出、活动贡献与最终峰值分开记录，便于定位失真发生在哪一段。
4. 【候选方案】保留原输入来源、位置引用与观测时刻，输出完整可测活动及峰摘要；摘要规则不反向决定输入中的哪些样本「算对象」。

【历史参考·非本模块确认】输入侧提示稿把 `local_contrast_topk` 描述为展示中使用的算子；本稿未核验该实现，不将列内对比、topK、归一化或按索引入网认作状态侧已确认规则。

【仅工作台展示】若使用输入侧提示稿所述的既有动画展示，只能继承「工具展示已实现、机制未验证」的证据级别，保持 `mechanismValidated: false`；不据此声称本稿两个候选已经实现。

## 五、「空间峰」的工作定义

【候选方案】令一个观测窗口中的活动为载体位置上的非负量分布；「空间峰」是某个局部活动极大区域及其周围连通的活动支持域，包含多个承载位置，且相对周边背景具有可测衬比。这是测量用定义，不预设其对应一个对象或实例。

| 可测项 | 工作口径 |
| --- | --- |
| 【候选方案】支持域 | 在已声明空间邻接上，用待定阈值取得连通活动区域；平台极大可作为一个极大区域处理，不强求单一最大点。 |
| 【候选方案】峰位 | 同时记录极大区域及支持域的活动加权中心，避免把质心当作唯一真实位置。 |
| 【候选方案】峰宽与形状 | 记录支持域范围及活动加权空间二阶矩；仅在有效的坐标维度内计算。 |
| 【候选方案】峰值、质量与衬比 | 分别记录最高活动、支持域活动总量、峰与邻域背景的差异；它们不是同一个量，也不自动等于置信度。 |
| 【候选方案】分布程度 | 记录活动承载位置数量及活动集中程度，以识别仅单点点亮或整域饱和的退化情况。 |
| 【候选方案】证据对应 | 记录来源窗口及可追溯输入支持位置；摘要可用临时引用，但不赋予持久实例身份。 |

【开放/未决】支持域阈值、背景邻域、最少承载位置数、多峰分割和合格误差阈值均未拍板。核验前需固定读出规则并扫描阈值敏感性，不允许逐例调阈值把失败改成成功。

【开放/未决】峰数不等于对象数；未形成合格峰不等于环境中对象不存在；二维峰也不证明已表达三维实体。

【开放/未决】工作台 1.1.0 的 `S-SPACE` 结构描述为「一物可多峰；先有局部活动，再求归组；深度 / 参照 / 自运动歧义保留」，其结构状态为 `confirmed`。本稿据此避免一峰一物假设，但按本轮六项确认范围，不将该结构记录另列为【用户已确认】。

## 七、下一步可核验项：不依赖动画成功

【候选方案】后续实现最小数值实验时，固定输入、随机种子、映射、读出规则和参数清单，保存逐窗口 / 逐轮活动数据及异常记录；本轮仅写实验设计，没有执行或通过这些实验。

【候选方案】使用无对象标签的合成稀疏坐标样本，先隔离检验成峰机制；再接入输入模块实际稀疏输出检验端到端行为。前一阶段通过不能证明输入算子有效，后一阶段通过也不自动确认三维或归组。

| 核验项 | 输入与对照 | 数值证据 / 失败判据 |
| --- | --- | --- |
| 【候选方案】保位与邻接 | 局部稀疏斑块平移；分别测试内域与边界 | 记录映射后峰位误差、峰宽及边界失真；破坏邻接或超出预定误差容限则失败。 |
| 【候选方案】最小成峰 | 孤立样本、局部多点及无结构散点 | 检查支持域、衬比、分布程度；单点独占或全域饱和不能被报为合格分布式峰。 |
| 【候选方案】近邻可分性 | 两个斑块的间距和强度比逐步变化 | 保存可分间距范围、峰位偏差及合并条件；不把合并后的单峰解释为已完成正确归组。 |
| 【候选方案】机制差异 | 甲、乙使用相同注入，并将乙的交换轮数设为零作消融 | 比较噪声显著度、漂移、宽度与误合并；若没有收益或代价超标，则不支持增加该交换机制。 |
| 【候选方案】有界与可重复 | 扫描强度、稀疏度、交换轮数；同配置重复 | 记录最大活动、总量及逐轮变化；发现无界增长、非有限值或不可解释差异则失败。 |
| 【候选方案】空窗与协议异常 | 空快照、无增量、缺片、重复和乱序分别输入 | 检查是否遵守事先声明的观测语义；把缺失证据误记为零活动观测或重复累计则失败。 |
| 【候选方案】不确定度与溯源 | 省略深度和不确定度；修改来源与坐标声明 | 不得生成无依据的确定深度或来源；未知字段的处理应可诊断并符合固定协议。 |

【开放/未决】定量容限及最低通过条件须在实验前确认；当前没有可宣称「已通过」的指标。即使局部实验通过，仍只支持其测试范围内的结论，`mechanismValidated` 的后续状态变更需另行评审。

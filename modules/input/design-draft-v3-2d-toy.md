# 输入模块短稿 v3：2D toy · 画面稀疏进 S-SPACE

【用户已确认】当前阶段先做 **2D 世界 toy model**，再规划升 3D；旧 3D／Minecraft 输入设计不作现行。

【用户已确认】讨论口径（2026-11-04，用户与输入模块）：2D 画面 → 分块局部对比 topK 稀疏 → 传入状态空间 S-SPACE。

【开放/未决】`mechanismValidated: false`。本稿是短确认稿，不是机制验收；未改 `architecture.json`。

## 1. 已确认方向

1. 【用户已确认】稀疏算法起点：**分块局部对比 topK**（每块最多留 k 个突出位置；不够少留，不凑数）。
2. 【用户已确认】每个保留点带 **原画面位置**；除光强外 **可以记录颜色**；颜色是观测通道，不是对象标签／ID。
3. 【用户已确认】**topK 打分可以让颜色参与加权**（例如亮度对比＋色差加权）。
4. 【用户已确认】**块大小、每块 k、对比与颜色权重等参数，等状态网络设计完再调**；输入侧本轮不锁数值默认。
5. 【用户已确认】不预装具体游戏对象编号或世界地图；观测入口只交适配器真实稀疏测量。

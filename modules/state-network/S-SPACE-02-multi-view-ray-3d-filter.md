## 一、范围、前提与非目标

【用户已确认】输入采用 Q1-A 分块局部对比 topK，先稀疏再赋射线；多路独立稀疏矩阵及各自射线分别 ingest。输入不先配对、不三角测量、不钉死世界点，三维交汇由状态侧活动叠出。K、块大小和幅度尺度仍由输入侧讨论，不重开已确认方向。

【用户已确认】观测口只收适配器真实稀疏测量及射线；概念补全、预测和回映不能通过此口变成新观测。S-SPACE / S-INSTANCE / S-SOURCE / S-HAVE / S-WANT 是职责小框，不等于五套独立物理网络。原生基本三维能力是要求，深度不确定的表达仍开放。

【候选】本轮承接 [S-SPACE-01](S-SPACE-01-sparse-feature-to-spatial-peak.md) 的分布式活动与可测峰形，扩展到逐路寄存、共享三维承载和多路模式筛选。S-SPACE-01 的二维局部投影、邻接交换只保留为历史候选，不自动升级为三维机制。其旧 `depth_evidence` 与未区分视角的更新表述，本轮按[输入 v1 契约](../input/interface-contract.md)及本文第五节讨论，不修改旧稿。

【开放】本轮不完成归组、同类多实例身份、移动跟踪、遮挡续接、概念调用与回映全套。峰数不等于对象数，多路交汇也不等于已归组；不写死三因子公式或任何学习更新式，不引入 Minecraft ID、地图、隐藏属性、配方或网格答案先验。

【开放】只读核对 [architecture.json](../../data/architecture.json)：初读为 1.1.0，写稿期间外部更新为 1.1.1，复核本轮三项内容未变。`S-SPACE` 记录为 `confirmed`，描述要求保留深度／参照／自运动歧义；`L-SPACE: P-IN-FEAT → P-SPACE-IN` 为 `candidate`；`L-GROUP: P-SPACE-OUT → P-INSTANCE-IN` 为 `unresolved`。这些是结构原值，不证明本稿机制成立，本轮未写入结构文件。

## 二、输入 v1 下的三层职责

| 层次 | 接收、处理与可查记录 | 边界 |
| --- | --- | --- |
| 【候选】1. 逐路驱动寄存 | 以 `(session_id, source_id, view_id)` 区分流，校验整帧后替换本路当前稀疏矩阵、射线、时刻和几何版本；记录接纳结果、有效期及原事件引用。 | 不等另一条路来凑对；寄存器保存外部驱动，不承担对象匹配或空间记忆。 |
| 【候选】2. 沿射线注入共享活动载体 | 将每个有效样本沿其正向未知距离展开为活动贡献，保留起点、方向、来源位置、误差声明与变换版本。各路贡献可在同一个三维载体上重叠，并可分别追溯、撤回。 | 不先挑一个深度点；共享承载不等于丢掉逐路证据，也不要求每一路有一套物理网络。 |
| 【候选】3. 多路共支持下的模式筛选 | 在几何可共同定位、时间兼容且来源可区分的贡献之间比较活动模式；形成、保留或削弱局部三维活动，并记录筛选前后分布及支持来源。 | 不把“有两路亮起”直接认作正确对应；证据不足时允许多解或不收窄。此层仍不签发实例身份。 |

【候选】三层是逻辑责任，可以共享存储和调度；为了核验，需能区分原始驱动、沿线注入贡献和筛选后活动。撤回一路驱动时不能靠清零整个共享载体实现；若存在内部持续活动，须单独标明其历史来源，不能继续计为当前多路观测支持。

【开放】活动载体可用三维采样位置、具有三维嵌入的稀疏节点或其他可复算表示；本轮不选定体素、神经元排布或固定核。计算域的近远边界、采样密度和预算须显式记录，域外表示“未承载”，不能当作已测得的空区域或距离边界。

【候选】单路未知深度先保留沿射线的分布式支持。若采用有厚度的支持域，测量角误差、标定误差和数值离散造成的宽度分开记录；缺失误差不表示零误差，任意加宽的核不能冒充传感器精度。路径长度与采样密度变化时需核对总贡献，避免仅因射线更长或格点更多就得到更强证据。

【开放】只有相机自身坐标而缺合法跨路变换时，可保留可解释的逐路记录，但不能进入共同定位筛选；缺必需射线或标定则按契约拒收。不同视角编号也不必然代表独立测量：同源复制、裁剪派生及重复事件不能增加独立支持数。

## 三、「三维模式筛选」工作定义

【候选】三维模式筛选是：在同一可解释三维参照中，由有效逐路射线贡献产生的分布式活动，经过明确的更新规则后，使证据更充分的空间支持域相对保留，使证据较弱或不一致的支持域相对减弱，并保留当前输入无法消除的深度多解。它必须能由保存的活动数据和来源记录复算，不能只用画面上的亮点判定。

| 要核验的说法 | 工作定义与测量方法 | 不能冒充成功的情况 |
| --- | --- | --- |
| 【候选】假交汇被压 | 评分端用隐藏真值预先划定真实支持域与错误交汇域；固定域、阈值和读出规则，比较筛选前后两类域的活动总量、错误／真实活动比及假峰数。要求错误相对量下降，同时真实域保留量、覆盖和位置误差满足预定下限／上限。分母为零或没有真实域活动时记失败或不适用。 | 全部活动归零、全域同比衰减、删掉弱真峰、只改显示阈值均不能算压假成功。评分端的“错误”标签不交给网络。 |
| 【候选】深度收窄 | 沿一个被评估射线的距离参数 λ 读取活动剖面；在相同计算域、分辨率及固定活动质量比例下，报告覆盖该比例活动的区间并集、总长度、各分量位置／宽度与峰数。比较单路、未经筛选叠加及筛选后结果，同时检查真值覆盖和三维定位误差。归一后的活动质量仅供测量，不自动称为概率。 | 错峰变尖、裁短计算域、降低分辨率、丢掉其他合法模式或零活动后报告零宽度，均不算可靠收窄。多峰不能只用质心或单一方差隐藏。 |
| 【候选】保留歧义 | 对观测完全相同但有多个合法空间解释的样例，报告多个活动域或未决深度及各自证据；检查结果对微扰、调度和随机种子的敏感性。 | 对称多解被数值扰动随机选成唯一峰，只能记录为错误确定化，不能宣称正确消歧。 |
| 【候选】承载原生三维 | 同时读取三维支持域及其三轴位置／范围；在多个深度和非单一平面布局中检查位置、宽度与分离度，确认更新实际作用于三维承载。 | 二维热图附一个外部求解的 z 值，或只有三维动画，不能证明网络三维承载与筛选。 |

【候选】“假交汇被压”仅在输入含可区别证据的测试中要求；几何上同样合法的替代解应进入歧义测试。[理论几何稿第二节](../input/feasibility-minecraft-dual-ray-3d.md#二像素为何能约束三维)已给出同一未配对像素集合对应两组不同三维点的反例。没有额外合法证据时，本稿两个候选都不能保证选择隐藏真值。

【候选】显式三角化对照先得到或给定跨路点对，再解射线交会、最近点或重投影优化，得到点及误差。本稿候选则把所有未配对射线投到共同活动域，通过逐路贡献的合并或活动竞争形成空间模式，不把点对表和求解后的点作为前置输入。两者受同样的可观测性限制；活动叠加不会凭空解决对应歧义，也不预先断言它在精度或效率上更好。

【开放】显式三角化可放在隔离的评分对照中，但若运行路径实际先配对求点、再把结果点亮，就不能作为本稿“由活动叠出三维”的机制证据。支持域阈值、活动质量比例、误差容限及独立来源判据均须在实验前固定。

## 四、两个可对照候选，均未选定

### 候选甲：逐路有界合并与跨路共支持门控

【候选】各路先在共享三维位置上形成可追溯的贡献场，同一路多条射线采用有界合并；再按几何、来源和时间兼容性，对不同路的支持进行有界合并与共支持门控。评审起点是：多路支持区域相对单路区域更显著，单路区域仍以未定深度保留；不预设所有空间位置都必须被全部相机看见。

【候选】该方案不引入递归邻接交换或跨位置竞争。它用来检验来源区分和多路叠加本身能取得多少筛选收益；同一路大量亮点或重复副本不得替代另一独立路。饱和规则、门控形状、单路保留量及尺度校准都待选。

【开放】候选甲能降低单路偶然响应的相对显著度，但真正的错误跨路交汇也可能得到同等支持，不能承诺抑制这些假峰。跨路强度未必可直接比较，不能把亮度相近当作匹配身份；一条弱路也不应因全路连乘而使所有真实模式消失。

### 候选乙：在共同注入上增加有限轮沿射线贡献再分配

【候选】复用候选甲的寄存、投影、初始活动及读出，在每条输入射线的候选深度位置之间设置有界的贡献预算；有限轮内，根据来自其他兼容独立路的支持，将本射线贡献向较有共支持的位置再分配，逐轮重算共享活动。无可区分支持时保留沿线分布或多个模式；预算不得被误读为“这条射线必须选且只选一个点”。

【候选】本射线的贡献及由它循环传播出来的活动不得成为支持它自己的新增证据；保留贡献来源账目，并设置无证据自激的对照。这里竞争的是同一射线所支持的多个深度位置，不预置局部邻居之间的抑制环路，不进行显式点对枚举后求交点。

【开放】再分配规则、保留底量、更新步长、调度、轮数、停止判据及如何避免重复计算循环支持均未确定；该候选可能放大初始伪峰、错误锁定、振荡或吞并弱峰，且仍不能消除信息完全对称的歧义。这些风险须通过消融和反例记录，不能靠平滑动画解释为收敛。

| 对照条件 | 候选甲 | 候选乙 |
| --- | --- | --- |
| 【候选】共同设置 | 同一逐路事件、有效期、三维域、采样、注入尺度和读出规则 | 复用甲的设置与初始活动 |
| 【候选】唯一主要变化 | 共支持门控，无跨位置迭代 | 增加有限轮沿射线贡献再分配；零轮须复现甲 |
| 【候选】核验重点 | 单路残留、多路伪峰、真实弱峰保留 | 相对甲的假峰变化、深度宽度、真值覆盖、错误确定化与调度敏感性 |
| 【候选】额外基线 | 保留来源的未经筛选有界叠加 | 同一基线，另做零轮、去掉来源区分与停止再分配的消融 |

【开放】上述方案只用于评审，不选定任何一个；禁止将未批准的「局部驱动+邻近支持抑制」写成确定结构。S-SPACE-01 的候选甲／乙与本节候选是不同实验问题，名称相同不表示继承批准或实现。

## 六、开放问题与下一步可核验项

【开放】尚缺活动载体与计算域选择、误差到沿线宽度的映射、跨路幅度可比性、来源独立判据、时间兼容与寿命、候选更新规则及读出阈值。当前载荷没有跨路描述子或匹配身份，topK 也不保证保留共同物理点；若实验显示信息不足，须先报告不足，再讨论接口扩展，不能要求输入暗中配对。

### A. 合成双射线几何对照：只回答可观测性与标定问题

【候选】评估端生成无语义标签的空间点、合法相机组局部标定和投影，单独保存真值及正确对应；允许在评分程序中显式三角化。正确对应、点坐标与评分结果不得送入待测网络。合成样例不证明 Q1-A 实际稀疏输出能保留共同点。

| 用例 | 保存与判据 |
| --- | --- |
| 【候选】已知对应、非退化双射线 | 检查像素到方向、单位、基线、正向距离、重投影残差及位置误差；通过只说明几何链路正确。 |
| 【候选】零基线、平行／近共线、远点、角误差 | 保存退化诊断、可行深度范围和误差敏感性；无唯一有限深度时不强报精确点。 |
| 【候选】错误对应、未配对集合多解、时间错位 | 展示不同合法解释或不一致残差；重现理论稿的多解反例。同步误差与物体运动分开记录。 |

### B. 网络活动对照：只交逐路稀疏矩阵与射线

【候选】在隔离试验中让未经筛选叠加、候选甲、候选乙接收同一批独立事件，不提供点对或几何求解结果。预先固定几何版本、计算域、分辨率、初始状态、随机种子、参数、调度和读出阈值，保存逐路驱动、注入贡献、每轮三维活动及来源；真值仅在运行后评分。

| 用例与消融 | 核验项及失败情况 |
| --- | --- |
| 【候选】单路未知 → 添加第二路；同索引但不同射线；多个深度与非共面点 | 比较沿线深度宽度、三维位置误差、真值覆盖及峰分离度；单路无依据定深、按索引匹配或只有二维变化均失败。 |
| 【候选】可区别的干扰交汇、重复纹理式多解、两路 topK 无共同点 | 分别评分压假与歧义保留；无共同点不能伪报深度成功。等证据多解被强行唯一化须单列失败。 |
| 【候选】甲／乙零轮／乙多轮；改变到达顺序、步长和种子 | 零轮复现甲；报告额外轮数是否降低假峰且保留真实覆盖，检查有界性、振荡、自激和调度敏感性，不以“变尖”单项判赢。 |
| 【候选】同源复制成两路、重复事件、单路多点高强度；禁用来源区分的消融 | 正常设置不得因此新增独立视角证据；比较错误收窄率，检查重复是否延寿。 |
| 【候选】一路有效空帧、缺测、过期、拒收、几何切换及异步运动 | 核对只改本路、拒收不污染旧驱动、过期不继续当当前共支持。内部历史活动单独报告；本项不验证遮挡身份续接。 |
| 【候选】计算域扩大、分辨率变化、角误差扰动与弱路尺度变化 | 报告边界截断、活动质量、真值覆盖及误差变化；不能靠域裁剪、采样数或强路支配取得虚假收益。 |

【候选】上述隔离实验之后，再用适配器真实 Q1-A 稀疏输出做端到端对照，单独测共同点保留率、覆盖、误交汇和失败场景。原始图像、稀疏结果、射线与活动应能逐层定位失真；几何对照通过、接口通过、网络活动通过分别记录。

【开放】本轮只完成讨论稿与文档一致性检查，没有执行几何实验、网络实验或端到端实验。后续结论须限定到测试场景及冻结参数；任何单项通过都不自动改变 `mechanismValidated: false`。

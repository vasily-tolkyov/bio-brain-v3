## 1. 范围与非目标

【已确认】概念网络提供共享的学习、补全、预测与目标反查基座；状态网络承载空间、实例、出处、当前已有与目标。S-SPACE / S-INSTANCE / S-SOURCE / S-HAVE / S-WANT 是职责名，不等于五套已批准的独立物理网络。[R1、R2]

【已确认】范围包括视频①–⑯及其与输入、状态、动作侧的边界。非目标包括实现脑网络、修改源码、替状态侧设计归组／三维机制、替动作侧拍板竞争／执行动力学、引入外置规划器或第二套规则知识表。[R0、R1]

### 目标反查：⑯

| 编号 | 机制规格 | 核对入口 |
| --- | --- | --- |
| ⑯ | 【视频规格】L0 从与结果同源的底层“要”线索认出目标→沿上升通道逐层补全→高层对低一层按⑭同网差集筛缺件→缺件是动作则进入竞争，否则作为子目标再钳，重复上行／补全／差集。 | R0；R4 storyboard ⑯A–E、`beat_goal_reverse` |

- 【视频规格】“要灯亮”与“灯已亮”分开；根目标和派生子目标都不能写成真实过去或学习样本，动作候选也不能钳成“已经执行”。认出依靠补全，不翻目标 ID／规则表。[R0、R4]
- 【视频规格】反查复用同一概念网，不另建规划器；各层上行补全不等于每上行一层就立即做一次差集。缺件读出使用高层补全向低一层的映射与该层已有图样。[R0、R4]
- 【未验证/开放】当前非动作缺件何时成为可达子目标、何时只是背景情景，仍需动作模块对齐；不能照旧说明一概排除非动作缺件，也不能造一个“执行红色”的动作来补齐演示。
- 【仓库回退】视频未展开的根目标持续重算、现实满足后清除、pending 防重复及父取消清子链，可沿 R3 §4.4 保留为待对接设计；其时序、归属、深度上限不由本备忘拍板。旧上限 3 与演示 1～2 跳不能被误写为机制已验证。

## 3. 已确认校准边界与 C0←状态三因子

### 已确认边界

| 事项 | 现行约束 |
| --- | --- |
| 写入靶点 | 【已确认】状态网络用三因子直接校准 C0 吸引子内部神经元连接，包括削弱、增强、新建；不是改返回边、桥接可靠性或外置规则账。[R0、R1、R2] |
| 更高层 | 【已确认】C1 由 C0、C2 由 C1 等用原有非三因子机制校准；不能将状态三因子向所有概念层广播。[R0、R1] |
| 返回 | 【已确认】返回只是信号通路，没有可学习的“返回强度”；返回信号本身可承载活动，但不能偷换成可塑可靠性参数。[R0、R1] |
| 现实学习 | 【已确认】真实外界输入引发的直接活动与补全活动都可学习；禁止恢复补全学习排除或全查询纯读。[R0、R1] |
| 内部预演 | 【已确认】内部预演不学习；目标／想象不能冒充真实经历。现实输入在预演期间到来时仍按其真实来源处理，不因推理正在运行而一律冻结。[R0、R1] |
| 遮挡／缺测 | 【已确认】照常相应小幅削弱，不设豁免；不能以“未知”字段把本应削弱的学习支路屏蔽。[R0、R1] |

【未验证/开放】缺测不豁免学习，并不等于伪造一个“测得为零”的输入样本；输入有效性、来源与覆盖事实仍应保留。哪些内部连接参与本次削弱、窗口与“小幅”的计量尚未锁定，需由校准规则与接口共同说明。

### 候选与开放接口（视频未讲清）

【候选】R8 提出用暂态责任迹把现实支持／差异关联到 C0 实际参与的内部连接；已有边接受有界调制，新边以独立生长资格处理。它还提出直接改 ρ、普通更新后叠加现实调制的主候选；这些选择及数学条件全部未获本轮批准。

【未验证/开放】状态需要交付何种可比较信号、怎样绑定实例／来源／时间、怎样定位实际内部连接，以及新建连接的资格如何构成，均是视频之外的未定接口。本稿不把 V2 的变量、三个因子的具体含义或方程写成已确认。

【未验证/开放】C0 是直接改现有 ρ，还是另有内部校准状态；若另账，怎样作用于同一内部连接而不形成第二套知识，仍需决策。ρ 与 H_color 如何共同保持色选择，三因子与共闪／单端／时间衰减的顺序、合并、抵消和饱和也未定。

【已确认】上述缺口只能在既定学习架构内解决，不能恢复可学返回强度、用输出抑制替代内部校准，或为了证明候选而禁止真实补全学习。[R0、R1]

# 【候选】S-SPACE-07：由锁定相机与适用范围计算相对位置

【用户已确认】相对空间位置沿自然计算过程产生，不给画面、外观或计算结果另起分类名称。K 已锁定；方块尺度或范围相等关系只在其几何条件适用时参与计算。载体 A 继续承载射线，条件计量在 A 外进行。`mechanismValidated: false`。

【候选】本稿直接说明这些方程能算出哪些数值、还需要哪些依据，以及缺少依据时哪一项计算没有产生。相对分辨的检查直接比较左右、近远和条件坐标与真值，不依赖一段判定文字，也不以“A 没有相机测深”否定已经由范围方程算出的关系。

【候选】采用采样时刻的相机局部坐标，X 向右、Y 向下、Z 向前；像素 u 向右、v 向下。物体的位置代表点取可见正对面的中心，或完整水平范围的中点。Z 是该点的前向深度，λ 是它到光心的距离；没有外参便不声称得到了世界位置，也不把可见面的中心当作尚不可见的体积中心。

【用户已确认】锁定 K 后，像素对应的射线方向与透视关系确定，射线左右由 u 分辨。实验固定 160×120、fx=fy=120、cx=80、cy=60、整数像素中心和未经裁剪缩放的图像。FOV 与这套投影核对；逐帧不能修改 K 来迎合观测。

【候选】从针孔关系出发，完整水平范围的两端在同一个 Z 上，真实长度为 S，投影端点差为 p，代表点像素为 (u,v)，则有：

```text
u = fx·X/Z + cx                 v = fy·Y/Z + cy
p = u_right − u_left = fx·S/Z    p > 0
Z = fx·S/p                     X = (u−cx)·Z/fx
Y = (v−cy)·Z/fy                λ = sqrt(X² + Y² + Z²)
```

【候选】p 是两端的坐标差，不是包含两端在内的像素列数。已知方块单位 b 时，适用的完整范围可写成 S=N·b；N 必须有明确依据，不能从“MC 由方块组成”直接补成 1。若各物体的 Ni 分别已知，就各自代入 Si，得到块单位的条件坐标。

【候选】若只知道所有参与计算的完整范围具有同一个 S>0，便有 `Zi/Zj=pj/pi`。投影范围更大者 Z 更小，投影范围相等者 Z 相等；不需要先给 S 一个数值。与此同时，可以直接计算：

```text
Xi/S = (ui−cx)/pi
Yi/S = fx·(vi−cy)/(fy·pi)
Zi/S = fx/pi
(Pj−Pi)/S = Pj/S − Pi/S
```

【候选】这些值保留共同 S 为单位，不假装已经知道 S 等于一块。若相等关系还得到其中一个物体已知范围的支持，共同 S 的数值随之确定；若各物体的范围并不相等，则分别使用各自的 Si，不能只按投影大小排近远。

【候选】这说明相对分辨来自方程本身：各 Si 已知时，每个代表点的 X、Y、Z 被确定；仅知共同 S 时，每个位置只剩同一个正尺度乘数，物间的左右方向、前向近远、Z 比及以 S 为单位的坐标差仍被确定。相等是方程算出的关系，不按物体序号强排先后。

【候选】射线左右与三维 X 次序分别计算。不同 Z 下，ui<uj 不必推出 Xi<Xj；实验中 u=110、Z=24 得 X=6，u=140、Z=8 得 X=4。前一个点在画面偏左，但三维 X 更大，两项关系都能如实输出。λ 同样由坐标计算，不能直接拿 Z 代替。

【候选】S、范围相等、边的几何语义以及完整端点都是 K 之外的依据。水平边必须与相机横轴平行，两端同 Z；这里采用正对相机的可见面，端点未被遮挡或裁剪。纹理、阴影和 UI 的边缘不能自动取得这种几何含义。实验从像素四连通外廓取中心和 p，正对与完整边的依据由显式合成声明给出；本轮没有实现任意 MC 截图的块数识别。

【候选】解释函数只接收 A、锁定 K 和范围／几何依据。依据里给出边方向、面法向、端点来源，以及本帧哪些像素范围具有已知块数或共同 S；不提供真实 Z、世界点、隐藏对象 ID、地图或深度缓冲。每一项依据绑定到当前图像，不能套用另一帧的范围记录。

【候选】若某个物体没有可用的 Si，也没有把它连接到共同 S 的范围依据，就不产生该物体的条件坐标。已经得到范围依据的另一物体仍可照常计算；只有两端坐标都算出时，才求它们的前向近远、Z 比及三维坐标差。撤去相等关系后，这些数值不会由默认值接替。沿射线只有一个像素、缺少可代入的边时，该项计算同样没有产生，不声称测到了深度。

【候选】同投影的深度置换必须继续满足原来的范围方程。实验把四个正对面的 Z 从 16、8、24、12 改为 8、16、12、24，并相应改变位置与尺寸，得到同一幅投影；但范围也由 2、2、2、2 块变成了 1、4、1、4 块。后面这四个数不能等于同一个 S，因此在仍要求共同 S 的请求中，不代入任何替代尺度，不产生条件布局数值。像素本身算出的射线左右仍保留。这个处理只检查范围方程，没有给那幅画面增加另一种称谓。

【开放】相同投影不一定揭露被隐瞒的错误范围依据。本轮只检验已经明示的范围、几何和观测是否允许所需计算；没有取得必要依据时不作深度声称，不把条件计算说成无条件获知真实世界。

【候选】A 的沉积保持不变：对本帧射线，在前向半空间按垂距计算帐篷核活动 `A(q)=Σ I·max(0,1−dist(q,ray)/h)`，实验 h=0.25 承载坐标单位。按需查询这些活动，没有持久占据网格、对象账本或历史账本。计算出的活动不是新的相机深度测量。

【用户已确认】原始事件及 A 的每条 `ray.depth` 都保持 `{"status":"unknown"}`，原因只是相机没有测量深度；这不是相对布局的分桶。解释层算出的 Z、坐标差和关系不会写回这里，不重新沉积，也不改变原射线。

【候选】[runtime.py](experiments/mc-relative-layout/runtime.py) 的 `deposit(K,image,capture,event)` 产生 A，`interpret(A,K,evidence)` 只读这些依据并进行计量。解释结果的 `measurements` 保存从像素实际算出的中心、边界与 p，`coordinates` 只收录已完成的条件坐标计算，`pairs` 只收录已算出的成对关系和数值；同时保留所用依据。这里没有对整个布局或单个物体的判定字段。

【候选】坐标条目的 unit 为 block 时，数值以块为单位；为 S 时，数值是实际坐标除以共同 S。单位只解释数值的量纲。未产生的坐标不占一个默认数值槽；未产生的关系不附加替代词。算术精度不能支持两个很接近数值的次序时，也不写入该次序关系。精确相等才给出相等关系。

【候选】单帧像素位置用于把测量、坐标和物间关系对应起来，不赋予跨帧身份。实验文件的顺序编号只便于打开证据，不进入运行时计算。输入、结果与评分文件是本次离线证据，运行时不把它们读回成账本。

【候选】真正的几何或捕获错配必须硬失败。例如，K 与 FOV 不符、参数偏离独立锁定的采集配置、射线不对应原像素、像素或依据绑定错帧，以及声明完整几何端点但外廓已缺损，都终止该请求。即使一起改 K、FOV 与摘要使它们彼此相符，也不能更换已锁定配置。不修射线、不改 K、不补边，不把失败请求改成只返回 A 的成功请求。

【候选】缺像素、缺必要字段、非法范围数值，或向 ray.depth 塞入测量／推算值，也会抛出异常；CLI 非零退出且不创建本次输出文件。真实背景零值和方程算出的零坐标可以存在，缺失值绝不填零。全过程无兜底、无账本、不加颜色，`mechanismValidated: false`。

【开放】本轮是精确端点、无测量噪声的合成实验。实际 MC 的采集认证、边识别、遮挡和误差范围仍需验证；摘要绑定不能独自认证伪造的原始图像。运行时的浮点容差仅处理算术精度，不代表真实像素误差范围。

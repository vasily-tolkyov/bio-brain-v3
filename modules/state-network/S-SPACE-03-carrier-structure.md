# S-SPACE-03：三维连续活动场承载结构草稿

【候选】本文整理 S-SPACE 的承载本体：固定空间单元怎样接收单路射线、保留来源、普通叠加并替换外部驱动。它是结构讨论稿，不是运行时接口规范，也不是假交汇筛选模块。

【用户已确认】`mechanismValidated: false`。用户确认的设计方向、候选参数、合成实验结果与机制验证分别记录；本稿不改 `architecture.json`，不把 S-SPACE-02 或实验候选改写为已批准机制。

【用户已确认】本轮不加颜色，不采用固定账本式结构；不对就报错，禁止兜底或静默修补。第 11 节按七项拍板原则修订，分别标明【用户已确认】【候选】【开放】；设计原则获确认不等于机制已验证。

## 2. 职责边界

【候选】承载本体承担四项逻辑职责，可共享物理存储，不据此增加四套独立网络：

| 逻辑职责 | 接收／持有／产出 |
| --- | --- |
| 【候选】逐路事件寄存 | 保存本路当前有效事件、来源、采样时间、几何／拓扑版本及寿命；不同路独立更新。 |
| 【候选】单路沿线沉积 | 将有效 ray 的预算分配到固定重叠三维 RF，形成可追溯的本路贡献。 |
| 【候选】共享场普通叠加 | 对共同参照中当前有效的各路贡献求和；保留逐路分量，支持撤回与复算。 |
| 【候选】活动读出 | 提供单路／合计活动、计算域、配置版本、误差状态和来源时间；不签发对象或确定深度。 |

【用户已确认】多路分别 ingest，输入侧不先配对、三角化或给出确定世界点。真实观测入口不把概念补全、预测、回映或预演伪装成适配器新观测。

【候选】一条未知深度 ray 形成延伸的空间支持带；其含义是“这些位置受到该观测的条件性驱动”，不表示射线上处处有实体，也不表示沿途为自由空间。多个活动峰不是已经归组的多个对象。

【开放】S-SPACE 与 S-INSTANCE 等名字仍是职责边界，不据此批准独立物理网络。实例身份、跨帧追踪、内部记忆、概念接口与校准靶点不在本稿重新设计。

## 3. 单元、场与来源表示

【候选】在一个声明的共同三维参照 F 中，为单元 i 固定中心 c_i 与重叠感受野。规则格点 `c_i=h(i,j,k)` 可作为首轮数值承载；中心不随射线、真值、活动峰或学习移动。每条 ray 可驱动多个单元，每个单元也可接收多条 ray。

【候选】沿用宽度实验的数值起点：固定帐篷基与归一化高斯核组合成分配函数 φ_i(x)，在可承载域内满足：

```text
φ_i(x) ≥ 0
Σ_i φ_i(x) = 1
```

【候选】σ 指基础高斯尺度；实际支持带还受 h、格点相位、边界归一和读出插值影响，不能把 σ 直接称为传感器误差或活动半高全宽。单元中心格点与射线积分采样点是两类对象；后者只是数值积分节点，不是硬距离箱细胞。

【候选】用以下量区分来源与活动，不要求把它们实现为对外字段：

| 量 | 含义 |
| --- | --- |
| 【候选】E_v | 逻辑流 v 的当前事件。流键起点为 `(session_id, source_id, view_id)`。 |
| 【候选】a_i,r | 当前事件内一条 ray 对单元 i 的预算分配。可按需复算，不要求永久存完整逐 ray 张量。 |
| 【候选】D_v,i | 本路当前帧所有有效 ray 的单元贡献之和。 |
| 【候选】A_i | 共享场中当前有效且可共同定位的各路 D_v,i 之和。 |
| 【候选】readout(x) | 对 A_i 作连续空间读出；可同时读取 D_v，保留来源分量。 |

【候选】规则格点实验可用三线性插值后除以 h³ 得到活动密度。单元活动量与密度分别记录；预算守恒检查针对单元活动量之和，不把读出密度宣称为深度概率。采用其他 RF 排布时，体积权重与连续读出需重新说明。

【用户已确认】固定 RF 规则，按需当场算；算不出须报错或明确未求值，绝不填 0。

【候选】可用惰性／稀疏求值实现，以重算时间换内存：单元坐标仍由固定规则确定，不按真值选位置；缓存失效后可从当前事件复算。完整视锥的密铺容量与实时更新尚未证明，不能把实验中按需查询的节点数当作全网络规模。

## 4. 单路沉积：固定总预算、域内均摊

【用户已确认】单条 ray 表达为 `r(λ)=origin+λ·direction`，未知深度不先挑一个终点；由强度先确定射线总预算 Q，再在域内沿线均摊；未校准时跨路标幅度不可比。

【候选】声明计算域 Ω、其参照版本及当前 RF 配置，取射线可承载部分：

```text
Λ_r = { λ ≥ 0 : r(λ) 位于 Ω }
L_r = Λ_r 的总长度
a_i,r = (Q_r/L_r) ∫[Λ_r] φ_i(r(λ)) dλ
Σ_i a_i,r = Q_r        （L_r 有限且大于零时）
```

【候选】在当前静止双相机夹具中，光心 z＝0、d_z＞0，Ω 的前向边界给出 `λ_near=near/d_z`、`λ_far=far/d_z`。near/far 是 z 平面，不是 λ 距离；斜射线的 L_r 应按单位方向计算。域外是未承载，不是测得空区。

【候选】只有明确选定实验映射时才取 `Q_r=intensity`，不将它作为缺失尺度时的默认值。固定总预算方向已确认，但强度到预算的比例、跨路幅度校准和单位尚未签认；输入强度不能自动读成深度可信度。扩大计算域会降低单位长度预算，加宽 RF 或增加单元密度不能凭空增加 Q_r。

【候选】单路帧内使用线性沉积：`D_v,i=Σ_r∈E_v a_i,r`。它对输入 ray 的数量与强度敏感；首轮不加同路 max、竞争、归一化选峰或抑制。一次事件形成当前驱动，不能在每次刷新／读出时再次累加同一份预算。

【候选】有限域边缘可沿实验归一分配权重，使预算仍保留在可承载单元中；这是数值边界候选，不表示边界处有更强的物体证据。窗口、σ、h 或读出配置改变时，不能把不同配置的旧贡献直接拼接；候选做法是按同一新配置重算有效寄存事件并整体发布。

【用户已确认】域外直接报错，未承载不等于空。

【候选】上述 Ω 只定义射线在域内的承载区间，不声称承载无限射线。Λ_r 为空、长度为零或无有限长度时直接报错，不沉积、不把预算转给其他 ray，也不补默认距离。对 Ω 外的查询直接报错，不以缺值或零作为成功结果。

【开放】Q_r 的正式尺度、一般方向的域裁剪、横向计算边界及参数热切换协议待定；错误码和返回形式待定，不改变直接报错原则。

## 5. 多路普通叠加与同帧边界

【用户已确认】各路分别 ingest；首轮只做普通叠加，单路支持与多解都保留，不要求每处必须同时得到两路支持。

【候选】几何能合法变换到同一参照 F、使用兼容承载配置时，共享场为：

```text
A_i(t) = Σ_v∈当前有效路 D_v,i(t)
```

【候选】这一步只在相同空间单元上加贡献，不建立跨路像素／ray 配对表，不先求交点再点亮，不使用共支持乘积、门控或沿线再分配。相交处更亮可以发生，但不能据此选定真实交汇、唯一深度或对象身份。

【用户已确认】输入侧应不重放；承载遇身份冲突直接报错，不做合并兜底。

【候选】按路保留来源分量与事件引用；不同路同时存在并不证明独立证据。重复身份按报错处理，不通过幂等吞掉、别名归并或合并贡献修补输入。同源复制、裁剪派生不能仅凭新的 view_id 就获得“新增独立视角”解释。普通叠加幅度不是独立支持数，更不是概率。

【用户已确认】后续若进行跨路几何筛选，默认同帧。本稿不实现该筛选，也不为满足后续筛选而推迟本路新帧替换。

【候选】承载快照可同时包含 A 的新帧与 B 尚未过期的旧帧，但应显式列出各自采样时间和帧来源；它只是“当前各路驱动的叠加”，不能称为同步时刻的三维重建。后续筛选只能另取已证实属于同一采样轮次／同步帧组的贡献；若只有一侧属于该组，不得默用另一侧旧帧补齐。

【开放】当前输入草案的 `frame_id` 是逐路标识，数字相同不证明同帧、数字不同也不自动证明异步。跨路帧组依据、采样同步声明、允许误差及缺路处理需联合对齐；本稿不新增已批准的帧组字段，也不将“有效期重叠”替代同帧。筛选何时读取这些分量仍属后续模块。

【用户已确认】首轮不做移动处理；几何或参照对不上直接报错，不混用不同局部原点。

【开放】移动相机组的参照迁移、重投影与自运动对齐留待以后另模块讨论；静止夹具不提供这些机制的证据。

## 6. 新帧替换与驱动寿命

【用户已确认】本路新帧整路立刻替换旧驱动，不等待其他路；不以平滑过渡为由让本路新旧两帧共同成为当前驱动。

【候选】接纳过程先校验并准备完整单路新贡献，再在一个可见提交点替换 E_v 与 D_v；查询只能看到旧帧或新帧之一，不能看到半帧。这里“立刻”指合格新帧接纳后的发布语义，不承诺尚未测量的零毫秒计算延迟。拒收数据不算已接纳的新帧。

【候选】替换时可重算 `A=Σ_v D_v`，或等价执行 `A←A−D_v旧+D_v新`，并保证读出一致性。保留逐路分量才能只撤本路；不能靠清零共享场撤回一个来源。

| 事件／时刻 | 状态与处理 |
| --- | --- |
| 【用户已确认】A 的合格新帧接纳，B 没有新帧 | 立即整路替换 A，不等 B；B 的驱动不因 A 更新而重置。 |
| 【候选】`valid`、完整、`samples=[]` | 作为有效空快照，立即撤掉本路旧驱动；其他路不受影响。 |
| 【候选】缺测／无效／过期状态通知，或不完整帧 | 缺测通知不当作有效空快照；不合格帧报错拒收，不注入、不替换有效驱动，也不延长旧驱动寿命。旧驱动仍按自身截止时间处理，不能冒充本次成功接纳。 |
| 【候选】本路当前驱动到期，尚无合格替代 | 撤回该路当前外部贡献；其他路照常保留。归零只表示没有当前驱动，不表示场景为空。 |
| 【用户已确认】输入重放或承载身份冲突 | 输入侧应不重放；承载遇身份冲突直接报错，不做合并兜底。 |
| 【候选】同事件同内容重复到达 | 按重复身份报错，不静默幂等接纳、不重新注入、不延寿。 |
| 【候选】迟到、采样时间倒退、到达时已过期 | 报错拒收；不得回滚到旧驱动或改成当前采样时间。 |
| 【候选】新帧有非法 ray、标定缺失或不支持字段 | 报错并整帧拒收，不用半帧污染本路；此前仍合法的旧驱动只保留到原截止时间，不作为错误请求的替代结果。 |

【候选】寿命从 `valid_until` 或明确协商的逐路 TTL 得到，按声明时钟解释；不是每次读出重新计时，也不是默认永不过期。首轮承载可在有效期内保持当前驱动、替换或到期时撤回，不另加时间累积、指数拖尾或无输入自激。

【开放】TTL 数值、采样与接收时钟换算、最大处理延迟、乱序窗口及缺测撤回策略尚未批准。

【用户已确认】记忆归概念／内部状态，不灌回观测；历史活动不能因外部驱动撤回而被继续算作当前相机证据。首轮不设计历史持续机制，也不预设独立账本。

【候选】核验时序例：A10、B7 分别接纳；A11 到达后场变为 `D_A11+D_B7`，不再含 A10；若 A11 与 B7 不能证明同帧，后续筛选不得使用这对组合。B8 完整空帧到达后只剩 A11；A11 到期后当前外部驱动为空。上述时间顺序不推导对象消失或同步三维。

## 7. 与 VisionSparseEvent / L-SPACE 的对齐假设

【候选】逻辑接收面沿用 `ingest(单路 VisionSparseEvent, 拓扑描述, 几何描述)`；这是对齐名称，不是已实现 API。视觉载荷版本、完整字段结构和接纳规则仍待输入／状态联合签认。

| 字段／结构 | 对承载的用途及边界 |
| --- | --- |
| 【候选】`session_id/source_id/view_id`、`source_path/provenance` | 区分逐路寄存与来源关系；工程 ID 不表示对象或跨路对应。输入侧应不重放；历史复现不进入当前真实观测入口。 |
| 【候选】`event_id/sequence/frame_id` | 用于逐路排序、重复身份和帧冲突检查；发现身份冲突直接报错；不同路同索引／同帧号不构成匹配或同步证明。 |
| 【候选】`position_index/topology_ref` | 保留原测量位置、拓扑及变换依据；索引不直接等于神经元编号。 |
| 【候选】`intensity/intensity_encoding/scale_metadata` | 为预算映射提供原始幅度与编码依据；Q 与强度的具体比例仍开放，不静默把亮度当深度概率。 |
| 【候选】`ray.origin/direction/coordinate_frame`、`geometry_ref` | 绑定采样时刻合法标定、米制光心、单位方向与共同参照；不强行令两光心相同，不用隐藏世界点补几何。 |
| 【候选】`ray.depth.status=unknown` | 展开域内支持带，不填默认终点、唯一距离或占据结论；其他深度类型需另外协商。 |
| 【候选】测量／角度／时间误差 | 分别保留“未声明”“显式零”和已声明非零值，不能相互替代。RF 基础 σ 不充当测量误差。 |
| 【候选】`sampled_at/received_at/clock_id/valid_until` | 分开采样、到达和失效时刻，约束寿命；不能以接收顺序或有效期重叠证明同帧。 |
| 【候选】`validity/update_mode/frame_complete` | 首轮按完整 snapshot 对齐；校验全部样本后整路原子替换。增量、不完整帧及局部缺测掩码不默认获得支持。 |

【候选】误差未知时，首轮仍可对收到的 ray 作基础 RF 沉积，但读出必须保留“条件于所交 ray、测量精度未定”的来源说明；不擅自加一个看似确定的误差带。相同数值射线在 unknown 与 explicit_zero 条件下可产生相同活动，却不能给出相同的精度保证。

【用户已确认】未知误差不等于零，不自动加宽，不另建误差台账；有误差声明再另议。几何、内参或标定不一致、缺合法共同参照时直接报错；内参虽很少变，仍是硬失败，不混用、不隔离部分路后返回替代合计。

【开放】收到明确误差声明后的处理模型、支持范围与具体报错形式待另议。

【候选】不支持或非法声明报错，不静默忽略、填零或修补。

## 11. problems-solutions：七项拍板原则与剩余讨论

【用户已确认】以下七项以本轮拍板为准：不加颜色，不固定账本式结构；不对就报错，禁止兜底／静默修补。文中的数学量用于解释计算，不要求新增台账、固定字段或常驻存储。

【候选】具体算法、缓存、版本和发布方式仍属实现候选；既有合成实验只提供有限证据。本文保持 `mechanismValidated: false`，不把设计确认写成机制验证。

### 11.1 误差：未知不等于零，有声明再另议

【用户已确认】未知误差≠零误差；不自动加宽，不另建误差台账。没有声明时不能推导误差上界，也不能用基础 RF 的 σ 代替测量误差。有明确声明后再另议处理方式，本轮不批准传播或展宽模型。

【候选】合法名义 ray 可按基础固定 RF 计算，并说明测量精度未定；原输入的“未声明”与“显式零”保持区别即可，不要求逐分量新建状态表。相同数值 ray 可产生相同条件活动，这不意味着相同精度保证。非法或不支持的误差声明报错，不填零、不静默忽略。

【开放】明确声明的类型、单位、相关性和适用条件，以及是否传播、如何传播，待实际声明出现后讨论。原稿的协方差传播和展宽公式不作为当前实现路径。

【候选】核验应检查缺失／null 不被补成 0，未知输入不触发加宽，显式零不被宣传为真实无误。既有宽带对照仅说明覆盖、串扰与容量的权衡，不能成为自动加宽依据；见[宽度实验失败记录](experiments/support-width-sweep/RESULT.md)。

### 11.2 容量：固定 RF 规则，按需当场算

【用户已确认】RF 规则固定，数值按需当场计算；算不出报错或明确未求值，绝不填 0。不能以固定账本式结构作为承载前提，也不能通过静默丢 ray、改粗 RF、裁域或只留 topK 隐藏资源不足。

【候选】可从当前合格输入按参数化 ray 做局部积分，以时间换内存。查询沿用完整 Λ 的 Q/L，不能按本次请求的格点数重新分 Q。可选择保守空间索引或可淘汰缓存作为加速手段，但不规定“事件账本＋索引＋缓存”的固定组合；缓存缺项须计算，不能推出值为零。

【候选】缓存若存在，须能识别输入、几何和 RF 配置变化；过期值不能当当前值。超时、积分未完成或资源不足时明确报错／未求值；接纳所需资源不足则报错拒收，不发布半帧或部分合计。只有完成所需计算后得到的实际 0 才能返回数值 0。

【开放】核函数、积分步长、索引、缓存、内存上限及延迟预算尚未批准。完整视锥容量仍需测量；缓存有界不能证明当前输入、积分源节点及临时计算的总内存有界。已有 `BudgetRF` 会预先建立沿 ray 的积分源节点，并未证明参数化按需积分的容量。

【候选】核验应比较按需求值与独立完整计算，改变查询顺序、淘汰缓存后重算仍得到相同结果，并检查资源不足明确失败。既有小域结果只支持数值一致性，不证明约 41.2 亿中心的密铺可行性或实时性。

### 11.3 强度：先确定射线总预算 Q，再域内均摊

【用户已确认】强度先映射为每条射线的总预算 Q，再在计算域内均摊。Q 不随积分点数、格密度、查询次数或其他路到达而增加；不同强度的 ray 不必有相同 Q。未校准时跨路标不可比，普通叠加幅度不能解释为可比的证据强度或独立支持数。

【候选】在编码与映射明确时可使用：

```text
u_r = decode(intensity_r, intensity_encoding, scale_metadata)
Q_r = κ × g_v(u_r)
a_i,r = (Q_r / L_r) ∫[Λ_r] φ_i(r(λ)) dλ
```

【候选】线性实验可显式选择 `g_v(u)=u`；这不是缺少编码、单位或尺度时的补救。无法解释强度或计算 Q 就报错，不把未知尺度填 1、不把非法负数取绝对值、不补 Q＝0。若单路映射已明确但缺跨路标校准，可计算该路条件贡献；合计不获得跨路标可比性，也不通过帧总和归一或相机数量平均伪造校准。

【开放】正式预算单位、强度映射、跨路标校准方法及不同采样密度的影响待定。真实曝光、饱和与不同算子造成的差异，不能靠数值范围相同认定已校准。

【候选】核验 Q 的线性响应、已知编码还原、域长度变化时总预算不变，以及缺映射明确报错。既有 `0.4×2` 与 `0.8×1` 的合成等值例只证明算术关系，不证明真实跨路标可比。

### 11.4 几何／内参：对不上直接报错

【用户已确认】几何、内参、标定与输入对不上直接报错。内参虽很少变，仍作硬失败；不混用兜底，不默认沿用旧内参，不猜坐标变换，也不剔除不兼容路后以部分结果替代请求。

【候选】接纳前检查采样时刻、拓扑、内参／外参引用、坐标参照和配置是否匹配。帧内混版本、必要变换缺失或几何已失效时，报错并整帧拒收。不同路允许各有正确的相机参数，但各自都须匹配该路输入且能合法定位到共同 F；这不等于允许错配标定混用。

【候选】正常新帧可在完整校验后一次替换本路贡献；显式配置切换也须完整校验后整体发布。切换输入失配、某路不能合法转换或重建依据已过时，切换直接报错，不自动重基重试、不隔离部分路发布。此前仍合法的当前驱动只按原寿命存在，不得冒充失败请求的成功结果；已撤销几何对应的贡献须失效。

【开放】错误码、几何匹配检查和原子发布的实现方式待定；硬失败本身已确认，不再作为“拒收或暂缓”的可选策略。移动参照处理不在首轮。

【候选】核验应覆盖内参错配、缺变换、混版本和失效几何均显式失败，失败不发布部分贡献。旧实验中“同 F 异版本共存”仅是给定合法几何的模型结果，不能授权任何错配或混用兜底。

### 11.5 域外：直接报错，不等于空

【用户已确认】域外直接报错；未承载≠空，未知≠零。记忆归概念／内部状态，不灌回观测。

【候选】读出按以下语义检查，具体返回形状尚未定：

| 查询情形 | 【候选】按已确认原则拟定的处理 |
| --- | --- |
| Ω 外 | 直接报错；不以 null、NaN 或 0 作为成功读出，不推断自由空间。 |
| Ω 内但计算未完成／资源不足 | 报错或明确未求值，不返回伪零或部分合计。 |
| Ω 内但必要几何不合法 | 直接报错，不剔除异常来源后继续返回合计。 |
| Ω 内且所需计算完成 | 返回实际活动，可为 0；只表示当前驱动计算结果，不证明没有物体。 |
| 无有效当前路／全部到期 | 若合法配置下已确定无当前贡献，数学活动和可为 0；说明无当前驱动，不称为空场景观测。 |

【候选】查询 ROI 不重新定义 Ω；显式扩域会改变 Λ 和 Q/L，须按新配置重算，不能直接追加另一份预算。序列化、插值或显示不得把错误、未知或未求值补成零；本轮不加颜色，也不新增显示方案。

【开放】域边界、错误返回和未求值的具体表达待定，不能因此退回“域外返回缺值即成功”。内部记忆的实现留给概念／内部状态职责，不在承载中新建记忆结构。

【候选】核验应检查域外错误、域内未求值和实际算得零三者不混淆。旧实验的 `[null,0,null]` 只证明缺值与零可区分，不满足本轮域外直接报错的验收要求。

### 11.6 输入身份：输入侧应不重放，承载冲突直接报错

【用户已确认】输入侧应不重放；承载遇身份冲突直接报错，不做合并兜底。不能通过别名归一、去重合并、自动拼帧或最后写入覆盖来修补冲突输入。

【候选】用输入已声明的来源和事件身份检查重复及冲突，字段方案仍待对齐。同事件同内容重传也应作为重复身份报错，不静默吞掉；同键异内容、几何或寿命冲突则报错拒收，不重新注入、不延寿。只改 source_id／view_id 不能把已识别的同一原始采样变成新观测；发现此类身份冲突直接报错，不归并原始采样后继续接纳。

【候选】同一物理相机的正常新采样仍整路替换旧帧。不同已声明传感器恰好给出相同 ray 或幅度，不仅凭数值相同判冲突；来源身份与活动数值须区分。裁剪或多算子派生的合法输入表示由输入侧明确，不由承载侧拼接成完整帧。

【开放】身份字段、来源真实性与冲突检测能力待输入／状态联合对齐；本稿不宣称能从 ray 数值检测所有隐瞒来源的复制。

【候选】必需身份缺失或无法解释就报错，不能靠 `independence=unknown` 绕过身份校验。合法来源身份也不自动证明统计独立。

【候选】核验应覆盖重复身份、改名复制和同键异内容均显式失败，且当前驱动不被合并、覆盖或延寿。既有“可信别名归一后幂等”的模型不符合本轮接纳原则，不能作为新规则通过的证据。

### 11.7 移动／遮挡／历史：首轮不做，以后另模块

【用户已确认】首轮不做移动、遮挡或历史持续；以后另模块处理，任何结果都不得冒充相机观测。记忆属于概念／内部状态，不写回当前观测贡献、不刷新原采样时间，也不算新增相机支持。

# 【候选】S-SPACE-06：MC 单幅二维画面如何进入三维状态空间

【用户已确认】MC 首版入口是**一张二维画面＋相机参数**；默认交付形态为稀疏化后的 **2D 亮点＋单路射线**。没有左右两路图，没有配对。当前目标是原型在 MC 跑通；现实多相机设计另议。本轮新建本文和隔离合成实验，不修改输入契约、旧稿或 `architecture.json`；`mechanismValidated: false`。

【候选】本稿的研究结论是：**一帧能提供成像方向和保留下来的强度结构；一般不能唯一确定这些方向上的度量深度。S-SPACE 可以先承载这份观测在三维参照中的活动／射线支持；若要进一步主张“还原了当时的实际三维位置”，必须说明新增的尺度、几何或经验依据。**承载计算可以成立，实际深度仍然未定，两者要分别核验。

【用户已确认】自然成像口径继续有效：场与亮度不贴真假标签，不以交点、亮度或活动形态决定输入资格。几何／内参／标定真正错配仍硬失败。无兜底、无固定账本、无填零、不加颜色。

## 1. 【候选】问题界定：要恢复哪些状态

| 标记 | 对象 | 本轮能讨论到的边界 |
| --- | --- | --- |
| 【用户已确认】 | 单次观测 | 同一时刻的一张画面与该画面的相机参数；输入模块先稀疏化，再为保留亮点赋射线。 |
| 【候选】 | 可见几何 | 保留位置可能来自哪些三维位置、有哪些可用尺度依据；不能把二维位置直接当成世界坐标。 |
| 【候选】 | S-SPACE 当时的活动 | 在明确参照、RF 和计算域下，由这一整帧驱动的活动。活动强度表达承载计算，不自动表达占据、距离或概率。 |
| 【开放】 | 完整实际世界状态 | 被遮挡表面、视野外部分、被稀疏化删除的细节、对象身份、速度和历史等，通常没有被这一帧充分约束；本轮不宣称恢复。 |

【候选】“单路”指只有一个相机视角，不是整帧只剩一条 ray。每个保留亮点各有一条 ray，整帧全部保留亮点一起加载。数值实现遍历 ray 或积分，不是逐 ray 发布、扫角或沿深度试探。

【候选】相机参数要区分：内参／投影和图像变换决定像素对应的方向；外参决定该方向落在哪个三维参照。只知道内参时，可以**显式选择采样时刻的相机局部参照**，将光心定义为该参照原点。这是坐标定义，不是猜出玩家世界位置。若请求世界坐标而没有合法外参，就报错，不能自动降成局部坐标后声称世界定位成功。

【开放】“相机参数”是否包含合法采样位姿、如何取得实际渲染投影、单位怎样对齐，仍须明确。不能从“MC 可读取某数据”推出隐藏世界位姿、深度缓冲、地图或方块命中答案已经获准进入输入。

## 2. 【候选】几何与信息论边界

【候选】以下采用已声明的针孔投影：图像 u 向右、v 向下；相机 x 向右、y 向下、z 向前；像素中心约定、裁剪／缩放和畸变模型均显式给出。对相机坐标中的可见点，投影为 `u=fx·X/Z+cx，v=fy·Y/Z+cy`。这是标准投影关系；实际 MC 相机是否符合该声明，另需核验。[OpenCV 相机模型](https://docs.opencv.org/4.13.0/d9/d0c/group__calib3d.html)

【候选】由上述关系反推，本稿得到：

```text
p = (u,v,1)
d_C = normalize(K⁻¹p)
d_F = R_F←C d_C                   # 仅在该变换已合法提供时
X_F(λ) = o_F + λ d_F, λ > 0
```

【候选】`λ` 是沿单位射线的距离，`Z` 是相机前向深度；两者通常不相等，局部参照中有 `Z=λ·d_C,z`。生成 ray 时归一化由成像模型推导的方向是明确计算；接收端偷偷修正不合法的来路方向是另一回事，后者禁止。

【候选】本稿推导：对任意 `s>0`，`(X,Y,Z)` 和 `(sX,sY,sZ)` 投影相同。即使 K 和相机位姿完全已知，只靠一个像素仍不知道 λ。单相机中不同像素的名义 ray 共用光心，不能靠它们彼此相交获得场景深度；光心附近活动叠加、邻近 RF 重叠或有限域边界也不补充深度证据。

【候选】尺度歧义不是全部歧义。每个可见方向还可能有不同深度安排；遮挡后的结构可以改变而不改变这一帧。场景先验能够排除部分解释，但必须把先验条件写出来；不能声称“任何单帧都不可能恢复任何深度”，也不能声称“MC 都是方块，所以任何单帧必然可恢复”。

【候选】信息论上，固定相机参数 C 和算法配置 θ 后，记世界状态为 W、原画面为 Y、稀疏输入为 E、承载活动为 A。若处理只使用该画面，则有确定性链 `W→Y→E→A`，所以 `I(W;A | C,θ) ≤ I(W;E | C,θ) ≤ I(W;Y | C,θ)`。这是本稿对处理链的推导：扩大状态空间维数不会凭空增加观测信息，稀疏化也不能恢复已删除的画面细节。

【候选】更直接的可核验判据是：若两套世界给出同一 E，固定承载必然给出同一 A。本实验恰有这样的反例。若仅考虑这两套等概率世界，观测后仍有 1 bit 的世界选择不确定性；这个数来自离散二选一设定，不是对真实 MC 世界熵的估计。使用随机种子也不能保证选中真实世界。

【候选】学习式单目深度可以用训练得到的规律作预测，但这不等于从当前一帧获得了新的测距观测。单图深度研究本身明确讨论整体尺度歧义；本文只引用这一边界，不沿用论文网络作为已选机制。[Eigen 等，单图深度预测](https://proceedings.neurips.cc/paper_files/paper/2014/hash/91c56ce4a249fae5419b90cba831e303-Abstract.html)

【候选】亮度也不能直接换算成距离：图像强度还与表面辐亮度、光照、曝光和渲染处理有关。本实验明确使用不随距离变化的表面辐亮度，检查几何歧义；不把反平方衰减当作未知场景中的默认测距规则。已有 `intensity` 是稀疏算子输出，未必等于原始像素亮度。

## 3. 【候选】可以独立拍板的路径

【候选】下面各项可以分别取舍，不是必须串行实施的流水线。A 解决当前观测的三维承载；B、D 讨论额外信息怎样约束深度；C 讨论尚未唯一时怎样表达；E 只列未来扩展。它们都不要求 MC 首版先有双目或配对筛选。

| 标记 | 路径 | 新增条件 | S-SPACE 承载内容与限制 |
| --- | --- | --- | --- |
| 【候选】 | A：单帧自然活动／射线支持 | 仅当前稀疏亮点与合法相机参数 | 固定 RF 上的整帧活动，保留未知深度。可先跑通这一段；不能据此报出唯一实际深度。 |
| 【候选】 | B：单帧几何约束 | 已知平面、尺寸、尺度或格点规律中明确获准的一项，以及在保留观测中识别其适用位置的依据 | 条件成立时可产生三维位置约束；条件不确定时保留多个解释，不能把假定写成相机测量。 |
| 【候选】 | C：多假设／约束集合 | 不必增加观测，但要设计表达与消费方式 | 表达尚可能的深度／结构关系；可以隐式计算，不要求固定候选槽或账本。多假设本身不消除歧义。 |
| 【候选】 | D：经验或学习先验 | 明确训练来源、允许使用的先验及当前输入信息范围 | 提供条件预测或候选约束，不能回填为本帧已观测深度。现有概念学习职责不在此重定。 |
| 【开放】 | E：未来单相机时序 | 额外帧、可信运动／位姿与时间依据，以及静态／动态场景处理 | 可利用平移带来的新信息；已超出“一张画面”的当前范围。本轮不实现，不成为首版依赖。 |

【候选】A 的建议验收措辞是“合法单帧输入已被 S-SPACE 在明确三维参照中承载，未观测深度仍未定”。若验收要求“实际可见表面的度量深度已恢复”，A 单独不够，必须另选能提供约束的路径并单独验证；不能靠改名把承载完成当成重建完成。

【候选】B 可以再拆成两项独立决定。已知平面 `n·X+b=0` 时，射线交点满足 `λ=−(n·o+b)/(n·d)`；只有平面来源合法、该亮点确实受此平面约束、分母非零且 λ 在合法前向范围时，才得到条件位置。已知正对相机的线段长度 L、完整可见投影宽度 p 时，有 `Z=fx·L/p`。**平面和 L 都是额外条件，不包含在 K 中。**

【候选】B 中“方块尺寸”也不能跳过观测解释：一段可见边可能跨多个方块，可能来自纹理而不是几何边，可能被遮挡或不与成像面平行。已知单位块长不能自动确定边属于几个块、表面在哪个格面、摄像机相对格点的偏移。不得预装对象 ID、地图、配方或已知世界点表来代替这些问题。

【候选】单视图测量研究展示了如何在附加几何条件下取得仿射关系、长度比及带共同尺度的测量；这支持“按条件缩小解集”的方向，不证明任意亮点已具备这些条件。[Criminisi、Reid、Zisserman，Single View Metrology](https://www.robots.ox.ac.uk/~vgg/publications/2000/Criminisi00a/)

【候选】C 可用概念量 `H(E,C,P)={与观测及明示先验 P 相容的三维解释}` 讨论。它是数学集合，不规定要存一张世界列表；可以由隐式约束或按需求值承载。单条 ray 的连续深度范围也不是固定若干深度箱。有限枚举若只抽到两个解，不能宣称剩余解已穷尽或已被排除。

【候选】A 的普通活动和 C 的联合世界假设不是同一对象。单元活动通常不保留“这些位置必须共同属于同一套世界”的全部耦合关系；不能把多个活跃位置当成同时占据。若 C 需要联合约束，须另行说明其组织和读出，不能声称现有普通叠加已完成。纯支持集合没有归一化概率；要谈概率，必须另给先验、似然和校准依据。

【候选】D 若只读 E，就只能使用 E 保留下来的信息；不能在状态侧悄悄再读原始稠密图、颜色通道或深度缓存。若未来要使用原画面上的稠密网络，输入范围与模块边界需要另议，本轮不改接口。模型对这两套同输入世界仍会产生同样预测／分布，不能保证区分实际是哪套。

【开放】E 中纯旋转不提供新的光心平移视差；单目运动还可能保留整体尺度歧义，未知动态物体运动会与相机运动混淆。真实平移尺度和合法位姿从哪里来、如何使用后续帧约束较早时刻，留给后续研究。本轮既不启用跨帧关联，也不把两次采样称为 MC 首版的左右图。

## 4. 【候选】S-SPACE 在未知深度时具体承载什么

【用户已确认】沿用[承载稿](S-SPACE-03-carrier-structure.md)与[自然成像口径](S-SPACE-04-false-intersection-filter.md)：固定重叠 RF、明确近远计算域、每 ray 固定总预算并在域内均摊、整帧沉积与普通叠加；固定规则按需计算，不要求固定账本。这里引用其已确认原则，不把旧双目实验配置升为 MC 默认。

【候选】对这一帧的每条 ray r，在声明域 Ω 中定义 `Λ_r={λ>0 | o_r+λd_r∈Ω}`、长度 `L_r` 和明确强度映射得到的预算 `Q_r`。一种可复算的承载表达为：

```text
a_i,r = (Q_r/L_r) ∫[Λ_r] φ_i(o_r+λd_r) dλ
A_i(t0) = Σ[r∈本帧全部保留亮点] a_i,r
φ_i ≥ 0，Σ_i φ_i(x)=1 时，Σ_i a_i,r = Q_r
```

【候选】此处 A 是**由观测驱动的三维活动**；ray 表示**位置可能沿该方向分布的几何支持**。它们不是稠密几何表面、深度图、占据概率、自由空间或已归组对象。这个解释不为场加“真／假”“可疑／可信”等标签，也不按形态分类删改自然活动。

【候选】域 Ω 限制计算范围，不是观测得出的深度区间。在没有深度先验时，只知道“本模型承载了这一段”，不能说“物体一定在 near/far 之间”。扩大域会降低单位长度预算，缩小域会提高活动密度；不能用更窄的域制造深度已确定的表象。Λ 为空、退化或不具有限长度则报错。

【用户已确认】域外直接报错；域内尚未求值／资源不足须报错或明确未求值，不能填 0。只有完成计算所得的实际零可以是数值结果，它仍不证明那里没有实体。未知误差不当零，不自动加宽 RF，也不另建误差账本。

【候选】默认只承载当前完整观测；正常新帧按本路替换，不累积为额外独立观测。历史、概念补全和预测若以后存在，不能刷新原采样时间或回灌观测口。本文的数值脚本仅做单帧纯计算，尚未实现流式替换、寿命调度、身份冲突检测或内部持续。

## 5. 【候选】与输入／S-SPACE 的交接名称

【候选】只读对齐[输入接口契约](../input/interface-contract.md)已有名称；逻辑接收面仍写作 `ingest(单路 VisionSparseEvent, TopologyDescriptor, GeometryDescriptor)`，接线称谓沿用 `L-SPACE / P-SPACE-IN / P-SPACE-OUT`。本文没有定义新正式 API 或更新端口；现有稿中的多路例子不构成本轮单路入口的前提。

| 标记 | 既有名称 | 本轮含义 |
| --- | --- | --- |
| 【候选】 | `source_id / view_id / frame_id` | 一个真实相机流的一帧；工程标识不编码对象身份，不存在配对键。 |
| 【候选】 | `samples[].position_index / intensity` | 保留二维位置与明确编码的强度；未列位置没有提供正驱动，不等于空空间。 |
| 【候选】 | `topology_ref / TopologyDescriptor` | 栅格尺寸、索引顺序、像素中心及图像变换可回溯；截图裁剪／缩放与 ray 必须一致。 |
| 【候选】 | `geometry_ref / GeometryDescriptor` | 绑定本帧投影、标定、参照、单位和有效时刻；实际相机投影需与描述相符。 |
| 【候选】 | `ray.coordinate_frame / origin / direction` | 在明示参照内的起点与单位方向；光心来自相机几何，不来自物体位置。 |
| 【候选】 | `ray.depth.status=unknown` | 不填写距离、终点、假设深度或世界点；B／C／D 的条件结果不擅自扩充该字段。 |
| 【候选】 | `intensity_encoding / scale_metadata` | 解释 Q 的依据；缺少映射就报错，不默认比例为 1。实验显式选择的比例不升为正式默认。 |
| 【候选】 | `sampled_at / clock_id / valid_until` | 只解释这一帧的时刻和可用期限，不是跨路同步窗口，也不允许拿过期帧补齐。 |
| 【候选】 | `frame_complete / update_mode / validity` | 保留完整快照、空帧与缺测的区别；整帧校验失败就不发布该帧活动。 |

【候选】承载读出可以提供 RF 活动访问方式、坐标参照、计算域／RF 配置及原观测引用，使读出能复算和追溯。这是语义要求，不指定新增字段、常驻 ray 表或缓存组合；无需为每个深度或对象建立固定条目。

【用户已确认】几何真错配硬失败；这与“不唯一”不同。一个合法像素对应很多深度不是错误，不能因此拒绝自然成像。像素索引、内参、ray、裁剪变换或采样标定互相矛盾，才须显式报错；不得自动沿用旧内参、修 ray 或返回部分贡献。

【开放】自洽但整体错误的相机标定，不能仅凭同一份 metadata 互相校验保证发现。真实接入需要相机参数与采集帧绑定、独立投影核对等依据；一旦发现实际错配仍必须硬失败。本实验只验证能显式构造的内部不一致，不声称已认证 MC 相机。

【开放】旧输入／状态接口稿仍含“重复幂等”等前轮候选，与后续承载稿的身份冲突硬失败口径存在待对齐处；本轮没有重写对方文件，也没有把单帧实验冒充完整协议一致性验证。时序、重放及重复身份均须在真实接入前单独核对。

## 6. 【候选】最小合成核验与实际证据

【候选】实验位于 [experiments/mc-monocular-state](experiments/mc-monocular-state/RESULT.md)。用同一相机在两个独立世界分别渲染一张 64×48 标量亮度图：表面前向深度分别为 4、8 个实验长度单位，后一世界同时将表面横向尺寸加倍。两者是替代世界，不是左右视图，不共同 ingest。

【候选】渲染按 ray 与不透明正对平面的最近交点取恒定辐亮度，背景为明示环境辐亮度。没有给场打真假标签、没有颜色通道；真值几何只交生成／评分端。该理想模型忽略 MC 纹理、光照变化、雾、阴影及后处理，因此证明的是单目投影的反例，不是某一实际 MC 场景已经拍摄成功。

【候选】稀疏示例使用 8×8 块、块内均值绝对对比、每块最多保留两个非零值，并按原像素索引处理并列。它只是已确认“分块局部对比 topK”方向的一个显式测试配置，不批准输入模块参数。承载只拿到稀疏观测摘录和相机描述，不读稠密图或 `*-world.json`。

【候选】为便于独立核验，实验采用 h=0.5 的固定三维帐篷 RF，在 Ω=`[-7,7]×[-5,5]×[0.5,12.5]` 上按需积分。该核不同于旧稿的高斯组合候选，不替换旧稿、σ 或正式实现。坐标使用合成长度单位并在夹具中显式记作 m，不能据此宣称实测 MC 已完成“方块→米”的标定。

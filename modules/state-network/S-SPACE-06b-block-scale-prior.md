# 【候选】S-SPACE-06b：方块尺度先验与已知 MC 内参

【候选】本文补充 [S-SPACE-06](S-SPACE-06-mc-monocular-state.md) 与[合成 RESULT](experiments/mc-monocular-state/RESULT.md)，仅记录本轮决定与候选解释；保留单幅画面、稀疏 2D 亮点＋单路 ray 的入口，不引入左右图或配对。`mechanismValidated: false`；不改 06、旧实验、输入契约或架构文件。

【用户已确认】采用现成 Minecraft 方块尺度：单位方块边长 `b=1 个方块单位`，作为显式几何先验，走路径 B。

【用户已确认】MC 相机参数固定且可确定。一旦从真实 MC 锁定版本、FOV 与投影，即将相应内参 K 视为已知，不对每帧重新猜测 K。

【用户倾向／待写入】成像与载体 A 的规则保持固定；变化的是输入帧及其驱动的 S-SPACE 活动。采用 B 不意味着逐帧学习或改造 A 的承载规则。

【用户倾向／待写入】成熟模块可以在载体 A 之外帮助解释；预测不得被改写成相机测量。具体模块、接入位置与实现尚未选定。

【候选】本轮 B 的依据是“已知方块边长 b＋已锁定的 MC 内参 K”。K 给出像素到视线的关系，b 提供尺度参照；二者要结合可识别的几何适用条件才能约束深度。图像分辨率、像素坐标、裁剪／缩放必须与锁定 K 一致；实际配置不符时硬失败，不改 K 迎合当前帧。

【开放】**把可见边识别成 N 个方块仍未解决。**已知 b 不等于每条可见边都长 1 块；边可能跨多块、被遮挡、发生透视缩短，或只是纹理／屏幕覆盖。需要识别几何边、有效端点、块数 N 及方向条件；不能默认 `N=1`，也不能借对象 ID、地图或隐藏命中结果完成识别。

【候选】极短几何说明：对端点完整可见、同深度且平行于相机横轴的边，长度 `L=N·b`、投影宽度 p 时，前向深度 `Z=fx·N·b/p`。例如 `fx=480 px、p=48 px`，N=1 得 10 块，N=2 得 20 块；这是条件算术，不是 MC 实测。斜边不能直接套此式，未知 N 不能补成 1。

【候选】相对布局可以描述方向、形状关系或仍差整体尺度的结构；度量深度要在尺度对应与几何条件成立后给出有单位的距离。先以方块单位表达，不默认改成米；与现有米制 ray／RF 的单位关系仍须显式对齐。已知 K 也不等于已知玩家世界位姿；前向 Z 与沿 ray 的距离 λ 须区分。

【候选】成熟计量辅助可读取当前稀疏位置、K、b 和 A 的只读活动，给出附适用条件、观测依据与误差说明的几何约束；成熟深度模型可给出带模型来源的预测。两者在 A 之外供状态解释消费，不成为自然沉积前的资格门，不给场贴真假标签，不把解释结果冒充新相机支持。

【候选】辅助结果不写回 `samples[].ray.depth`；在当前未知深度入口中仍保持 `ray.depth.status=unknown`。由已知尺度计算的条件深度与模型预测都须保留各自来源，不改称相机直接测深；不新增账本。需要读取原始稠密画面的模块，其输入范围另议，本轮不扩展输入契约。

【候选】无兜底、无填零、不加颜色。发现相机、ray 或所用几何约束与真实几何不符，相关几何请求硬失败，不修射线、不补块数、不用替代深度返回成功。合法观测存在多解与几何错配不同；辅助无法确定深度时，不抹除 A 已自然形成的活动。

【候选】06 的缩放反例仍说明未识别尺度对应时可以多解；若已识别某条边确实长一块，任意整体缩放就不再满足这项条件，不能用旧反例否定 B。旧 32 项检查没有验证块数识别或 B 的度量恢复；本附录不重跑或升级旧实验结论。

## 模块交接

- 【已确认】状态 → C0 的三因子靶点是内部连接的增强／削弱／新建；C0 → 状态的返回仅传信号，没有可学习的“返回强度”。
- 【候选】沿用兄弟模块的 L-CALL / L-RETURN / L-HAVE-QUERY 等名称，以及输入侧 VisionSparseEvent / BodySignalEvent / ActionEfferenceEvent 草案名；端口、编码和时序待联合对齐，详见设计备忘 §4。
- 【视频规格】目标从 L0 底层同源“要”线索认出，逐层上行补全，高层对低一层做差集；缺件为动作则交竞争，否则作为子目标再钳。
- 【未验证/开放】L-GOAL 当前结构端点与底层注入的映射、非动作缺件与情景的界限、状态校准怎样写入 ρ／色记忆 H，尚需对齐；不能据此改换学习架构。

# 输入模块：MC 单路当前方向

【用户已确认】MC 首版采用单路 2D 视角＋可锁定相机参数 K；先稀疏，再给保留位置赋方向射线。

## 当前方向与职责

- 【用户已确认】每个保留点先来自稀疏测量，再由相机几何获得方向射线；`ray.depth` 保持未测，禁止把推算／预测深度写回观测或 `ray.depth`。
- 【候选方案】整帧亮点集合连同位置、强度、时间、来源、拓扑与 `geometry_ref` 一次交给状态侧；全部检查完成后才接纳，不逐 ray 渐进发布。
- 【候选方案】按状态侧现行口径对齐：成像／承载底座 A 固定，稀疏亮点经射线在固定 RF 上沉积自然场；变的是画面与 S-SPACE 活动。输入不选 RF 参数或用解释结果重造观测。
- 【用户已确认】自然成像不贴真假标签；输入不交对象 ID、地图或配方；几何／K 真错配硬失败。
- 【候选方案】相对位置在状态侧 A 外按条件计算：锁定 K 提供方向关系；三维左右、近远和条件坐标还需适用的方块／等范围依据，缺哪项依据就不产出相应数值。不设置 resolved／inconsistent／partial 分桶，无兜底、无账本、无缺值填零。
- 【候选方案】成熟模块只在 A 外作解释／先验，不能替代 S-SPACE 底座，不能经输入伪装成新观测；原始观测及 A 不因这些解释被回写或重新沉积。
- 【开放/未决】分块局部对比 topK 是稀疏化候选，块大小、保留数、对比及幅度尺度尚未锁定。本文以 K 专指相机内参，以 k 表示每块保留数，避免混用。
